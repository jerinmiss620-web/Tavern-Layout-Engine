# TLE 可选功能包 · 正式发布（Core 0.3.213）

可选功能包安装的是**独立酒馆助手脚本**。TLE 只负责下载、安装、启用、停用与卸载；具体功能仍在各自的入口中操作。**配套侠是 TLE 内置功能**，无需作为可选包另外安装。

| 功能包 | 具体功能 | 版本与作者 | 实际入口 |
| --- | --- | --- | --- |
| **Freesia 覆盖侠** | 气泡居中／自定义字体／行高与字间距／滚动条宽度／头像定位 | v1.88.6 · 小松鼠 & ChatGPT（小松7） | 底栏 → 扩展菜单（魔法棒）→ Freesia 覆盖侠 |
| **主题绑定壁纸** | 主题绑定壁纸／多图随机切换／跨文件夹选图／配套侠联动 | v4.1 · 小松鼠 & Gemini | 酒馆原生「背景」面板 → 顶部工具栏 → 主题壁纸绑定管理器 |

两张卡片统一显示「功能名称 → 具体功能短句 → 版本和作者 → 实际入口 → 状态及按钮」。「··· 更多」均提供完整功能分组、使用步骤、注意事项。未来新功能包必须遵循 [统一展示规范](DISPLAY-STANDARD.md)。

## 使用方法
1. 保持正式版 TLE Bootstrap 启用，打开 **TLE 控制面板 → 可选功能包**。
2. 在功能名称右侧点击「··· 更多」，查看完整介绍、使用方式和具体入口。
3. 点击「安装并启用」；如果系统检测到已安装的相同 UUID，TLE 不会覆盖旧脚本，请在酒馆助手中手动管理。
4. 安装后刷新酒馆，在上表所示位置打开独立脚本。两个功能包可以只装其中之一，也可以同时使用。
5. 停用与卸载均可通过 TLE 功能包卡片或酒馆助手全局脚本列表完成。

## 数据与安全
- 从固定 GitHub 仓库的不可变 Commit 获取脚本；备用下载线路包括 jsDelivr、Fastly jsDelivr、TestingCF jsDelivr。
- 严格校验文件大小、SHA-256、允许的来源、完整 JSON、预期脚本名称和 UUID；校验未通过不安装。
- 只修改目标的酒馆助手全局脚本记录，不整体重建或覆盖脚本库。
- 停用或卸载不会主动清空已有的主题 CSS、字体本地存储、图库及壁纸绑定记录。
- 本地字体保存在各设备自身环境，PC、Android 与 TT 不自动同步。
