# TLE Remote Loader Stable 0.3.2 TEST — 默认自动安装

## 新增
- 为正式版通道增加 `tle.loader.stable.autoUpdate.v1` 持久化选项。未设置时默认自动安装已开启；显式设为 `false` 则始终不自动安装。
- 公开 `getInfo().autoUpdateEnabled`、`setAutoUpdateEnabled(boolean)` 和诊断状态，供 TLE 折叠面板控制。
- 启动时先恢复已授权、已验证的旧版本，再静默下载/验证正式版清单；发现高版本时，满足严格安全门槛才无须弹窗自动升级。

## 安全门槛
- 自动安装必须同时满足：当前实例已运行且健康、Loader 自动恢复曾获授权、Last Known Good 缓存通过校验且版本匹配当前实例、更新版本高于当前版本、没有主动关闭自动安装。
- 仍由原 Loader 的 `loadRecord` 负责验证源文件的 SHA-256 / UTF-8 字节长度、备份上一版本、脚本装载后健康检查与失败自动回滚。
- 无缓存、缓存不一致、当前实例异常、首装未授权、断网或存储失败时跳过自动安装并报告原因；不以「默认开启」为由绕过安全检查。
- 用户主动点击「手动安装」时仍保留原生确认对话框。
- 仅稳定通道；测试通道不会被自动提升为正式版。

## 发布状态与迁移
- 此为独立开发分支测试候选，正式 `main/latest.json` 仍指向 TLE v0.3.203。
- 需要一次性以 Loader 0.3.2 替换旧 Stable Loader 0.3.1；旧版没有 Loader 自我更新能力，因此无法隔空替换加载器自身。
- 检查 ST/TT 和移动端的长期自动恢复、无网络、缓存不一致、回滚后再启动行为后才能推广。
