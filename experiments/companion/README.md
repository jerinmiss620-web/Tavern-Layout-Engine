# 配套侠 · TLE 独立测试版 Dev1

基于稳定版 Core **v0.3.211** 复制开发，正式版 `main/latest.json`、Loader、Bootstrap 均未修改。

## 安装与回退
1. 备份配置和聊天；**停用原本的 TLE Bootstrap / Loader 及任何独立 Core 脚本**，避免相互覆盖。
2. 下载同目录的 `TLE-companion-dev1-import.json`，在酒馆助手中导入、启用，然后刷新酒馆。
3. 右上角「会话侠」新增「配套方案」页；当前角色可保存并应用方案。
4. TLE 设置 → 信息站设置内增加「配套侠 · 保存当前 / 管理方案」。
5. 测试结束，停用此实验脚本，重新启用原本的 Bootstrap / Loader 并刷新酒馆即可恢复正式版。

## 功能
- **仅当前角色**：使用原生角色头像文件名作为绑定 key，不依赖角色显示名；群聊不参与。
- **保存当前**：读取现有快速切换项目——连接配置、接口来源、模型、预设、推理格式和 UI 主题；可单独勾选保存。
- **编辑/复制/覆盖/删除/默认**：每个角色可有多份命名方案。
- **应用**：使用 TLE 现有 `quickCatalog` 与 `applyQuickChoice` 原生切换逻辑。异常会提示完成了多少项并停止，不显示虚假的“全部成功”。
- **壁纸**：不直接保存或切换壁纸。主题变化由独立的「主题壁纸绑定 v4.1」处理；渐隐侠仍使用现有镜像同步机制。
- **自动应用**：默认关闭；在配套侠管理器中可选启用。角色切换时只尝试当前角色的默认方案；只有一份方案时可以作为候选。不会在原角色的不同聊天之间重复应用。
- **存储**：`localStorage` 键 `tle.companion.v1`。TT、PC、不同浏览器不会自动共享，停用脚本不会自动删除方案。

## 测试限制和风险
- 尚未在 PC SillyTavern、iPhone TT、Android TT 上进行实机回归。已经验证 JavaScript 语法、JSON 格式和导入包与源码一致。
- 原生预设、模型下拉框在 TT 中可能被宿主卸载。如果当前无法读取，保存面板会提示，不会猜测选项 ID。
- 应用多个项目不具备事务回滚。若原生选项已删除或切换失败，可能已有前面的配置生效；会明确给出停止提示。建议先用两个配置相近的测试方案试验。
- 模型所属的接口来源切换后，模型列表可能异步刷新；首次验证时观察是否有失败提示。
- 暂未实现多角色共享方案的绑定 UI、全量导入/导出及日夜定时切换。这些功能不应被误认为已完成。
- 当前保存的是当前设备/浏览器的方案数据，不是 SillyTavern 服务端跨设备同步。
