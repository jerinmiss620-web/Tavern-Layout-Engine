# Core v0.3.259 TEST · 整理侠资源整理与查找替换分离

- 整理侠标题行新增「资源整理」与「查找替换」两个原生按钮标签，每次打开整理侠默认进入「资源整理」。
- 资源整理页独立保留资源分类、分组目录、资源名称筛选、同步、导入/导出、分组管理及批量操作。
- 查找替换迁移到独立页面，独立承载内容搜索、替换输入、规则组合、范围选择、备份与恢复、预览及结果列表。
- 内容查找不再占用资源整理第三分栏；资源名称筛选与内容搜索使用各自输入框，互不覆盖。
- 「当前筛选范围」与「已选资源」范围继续读取资源整理页的筛选条件和已选项目；原有内容扫描、预览、替换和备份恢复流程保留。
- 资源整理与查找替换页面分别管理自己的列表和状态；切换标签不清空资源分组、选中状态或内容规则。
- 不修改分组数据结构，不改动正式 Stable Core、Loader Runtime、Bootstrap；仅更新开发分支测试通道。
