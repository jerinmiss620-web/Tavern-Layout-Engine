# TLE Core v0.3.259 · 整理侠分组管理与更新面板原生按钮

## 整理侠与资源管理

- 保留全局搜索和整理侠两个独立入口；整理侠直接使用酒馆原生抽屉，不另建重复的搜索入口或资源管理器。
- 桌面端采用「资源类型 / 分组目录 / 资源列表」三栏；移动端使用紧凑单栏布局，各区域保留独立滚动和原有筛选能力。
- 世界书统一识别全局启用、角色主要绑定、额外绑定、未绑定和疑似孤儿状态；提供对应筛选。角色卡懒加载扫描仍按需触发，无法从酒馆数据还原的历史关联不伪装成已确认的孤儿关系。
- 「查找和替换」使用单个酒馆原生复选框切换模块；原资源名称搜索、内容规则、扫描、预览、替换与备份恢复流程保留。
- 预设管理区工具栏重排；输入框和选择框按可用宽度伸缩，长路径编辑区保留整行。

## 分组管理交互

- 分组工具栏顺序为「创建分组 → 自动分组 → 管理分组」，后接重命名铅笔和批量删除垃圾桶图标。
- 管理模式使用文件夹图标及原生按下状态，不再用 ✓ 表示管理开关。
- 勾选恰好一个自定义分组后可重命名；勾选多个自定义分组后可批量删除。重命名不依赖当前资源视图。
- 重命名与删除确认均使用单行图标操作：✓ 确认，× 取消；悬停和无障碍名称说明具体操作。
- 「全部项目」和「未分组」为系统目录，不可重命名或删除。
- 删除分组只移除分组定义和归属映射，组内资源移回「未分组」，不会删除资源；批量资源删除仍遵循酒馆原生删除能力和安全限制。
- 保留既有分组 ID、存储键、资源归属、全部分组备份格式及主题分组同步。

## 更新面板与兼容性

- 「检查更新」「启用 Loader 接管」「检查 Loader 更新」统一使用酒馆原生 `.menu_button`；删除旧 `.tle-update-check` 自定义外观规则，不覆盖主题的按钮背景、边框、圆角、尺寸和字体。
- 保留默认收起的酒馆原生「版本与更新」折叠区、自动更新开关、版本状态、可更新提示、手动检查与安装流程。
- 信息站总开关继续由导航显示模式决定；保留逐项设置。配套侠初始化建立当前角色基线，日夜定时按角色记录时段令牌，保留手动覆盖、逐项部分应用和缺项原因提示。
- Stable Loader Runtime v0.3.6 与固定 Bootstrap v1.0.6 不变；既有缓存、设置、Last Known Good 和 Previous 回滚机制不变。

## 安装说明

常规安装和更新仍由固定 Bootstrap 自动加载 Stable Loader 与 Core。此版本的酒馆助手导入 JSON 仅作为禁用状态的独立备份，不要与 Bootstrap 同时启用。
