# TLE v0.3.245 — Test

## 修正整理侠原生复选框结构

- v0.3.244 的开关使用了裸 `label`，遗漏 SillyTavern 原生 `checkbox_label` 类，导致复选框与文字纵向堆叠，出现异常的大色块布局。
- 本版改为酒馆原生 `label.checkbox_label` 结构，内部仍只有一个 checkbox input 和「查找和替换」文字 span。
- 不添加自定义 CSS、尺寸、背景、边框、圆角或颜色规则；完整继承当前酒馆主题的原生复选框样式。
- 默认不勾选，对应资源管理；勾选进入内容查找与替换；取消勾选返回资源管理。
- 保留原有搜索词记忆、规则加载、扫描、预览、替换、备份恢复及下方资源列表的选择机制。
- 浏览器与 ST 验收脚本增加 `label.checkbox_label` 结构断言。
