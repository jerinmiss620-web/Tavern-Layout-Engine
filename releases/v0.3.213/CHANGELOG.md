# TLE Core v0.3.213 — 可选功能包展示与说明统一

## 功能包卡片改造
- 覆盖侠与主题绑定壁纸改用 **同一套卡片渲染函数**，布局统一为：**名称 → 具体功能短句 → 版本和作者 → 实际操作入口 → 安装状态和操作按钮**。
- 覆盖侠短句明确为「气泡居中／自定义字体／行高与字间距／滚动条宽度／头像定位」，不再用含混的「字体管理、排版、留白与头像调校」代替。
- 主题绑定壁纸短句明确为「主题绑定壁纸／多图随机切换／跨文件夹选图／配套侠联动」。
- 覆盖侠作者：**小松鼠 & ChatGPT（小松7）**；主题绑定壁纸原脚本作者：**小松鼠 & Gemini**。作者与版本在两张卡片的相同位置。
- 「··· 更多」使用固定可见的文本符号，不依赖 Font Awesome 图标，降低图标未加载时的空白风险。

## 「更多」弹窗补全
- 两个功能包统一使用 **用途简介、版本/作者、实际入口、主要功能分组、编号使用方法、注意事项** 的顺序。
- 覆盖侠补充：气泡居中与留白、最多三楼辅助线、在线/本地字体与字体库、行高/字间距/2em 首行缩进、TT 原生字体比例、滚动条宽度和 Gutter、Char/User 头像定位、双态实时预览与常驻使用、CSS 写入及撤销。
- 主题绑定壁纸保留原先完整的跨文件夹选图、「返回并追加」「保存设置」等实际操作步骤，并统一元数据和栏目格式。

## 后续功能包强制规范
- 新增 `optional-modules/DISPLAY-STANDARD.md`，明确所有新功能包应有的展示字段、真实入口与作者核对方式。
- 新增自动回归检查 `tests/tle-optional-presentation.test.mjs`，验证两个卡片字段顺序、统一动作按钮、弹窗信息完整、展示元数据与 manifest 一致。
- manifest 中规范原作者署名和功能介绍，与用户界面显示保持一致。

## 不变
- 两款独立脚本仍为 **覆盖侠 v1.88.6** 与 **主题绑定壁纸 v4.1**，脚本原文件、UUID、安装行为与本地数据不变。
- 内置配套侠、渐隐侠、楼层侠、会话侠、诊断与 TT ChatSurface 功能不改。
- Bootstrap 1.0.6 与 Loader 0.3.6 不变，继续沿用现有安全校验和失败回滚机制。
