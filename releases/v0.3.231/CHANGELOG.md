# Core v0.3.231 · 整理侠工具按钮恢复主题原生样式

## 修正
- 整理侠标题栏的同步、导入、导出三个操作按钮全部继承 SillyTavern `menu_button` 原生样式，不再自定义背景色、边框、圆角、内边距、字体大小或行高。
- 修正整理侠通用按钮规则：仅重置非 `.menu_button` 按钮，避免高优先级选择器覆盖主题对原生按钮的配色、边框和字体定义。
- 三个按钮只保留必要的 flex 排列、图标对齐和最小触控尺寸；同步与 JSON 导入/导出行为不变。

## 保持不变

- 不修改 Stable Core、Stable Loader、Bootstrap 或正式 `latest.json`。
