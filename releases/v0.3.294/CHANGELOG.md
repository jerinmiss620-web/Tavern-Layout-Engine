# Core v0.3.294 · 角色专属预设条目方案与全局世界书多选

基于正式 Core v0.3.291 整合，保留现有 Stable Loader Runtime v0.3.6 与 Bootstrap v1.0.6。

## 配套侠：角色专属预设条目方案

- 每个角色独立保存预设条目的稳定 identifier 与启用状态，不复制预设正文、名称或顺序
- 预设条目改名、编辑正文或调整顺序后，仍按 identifier 匹配；新增条目保持原生状态，只有重新读取并保存方案后才纳入
- 删除、锁定或缺失条目分别识别；可用条目继续独立应用，并提示未能应用的项目
- 共享全局预设时，切换角色前先恢复原始预设的条目开关状态，避免角色之间串用
- 原始状态无法安全恢复时，阻止新方案继续应用；原生提示词管理器保存前先恢复预设基线，恢复失败则取消保存
- 保存方案时校验当前加载的预设名称，避免把另一个预设的条目状态写入角色方案

## 配套侠：全局世界书选择器

- 移除可见原生多行列表框，改为折叠式下拉复选清单，每本世界书独立勾选
- 已保存但当前未读取的世界书继续显示为已选、禁用项，避免编辑方案时意外丢失
- 保留原生多选数据源及 selectedOptions 保存路径，不改变方案数据结构
- 浏览器支持 Popover 时使用顶层弹出层，避免被保存面板滚动容器裁切；不支持时回退为面板内下拉

## 验证重点

- 预设条目标识匹配、角色隔离、预设编辑/排序、增删/锁定条目、共享预设基线恢复与保存拦截
- 世界书下拉展开/收起、逐本勾选、数量摘要同步、点击外部关闭与 Escape 关闭
- 缺失世界书保留、禁用状态与重新启用行为；原生多选数据源及方案读写路径不变
- 自动化回归与发布链核验通过后，再进行 ST / TT 实机验收；自动化测试不替代真实宿主验收
