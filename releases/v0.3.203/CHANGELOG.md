# TLE v0.3.203 TEST — Loader 更新入口恢复

- 基于完整 v0.3.202 正式版源码恢复版本显示及 Loader 联动。
- TLE 设置标题下显示运行实例的实际版本 `HOST_WIN[INSTANCE_KEY]?.version`，而非只从下载文件名推测。
- Stable Loader 0.3.1 通过只读 `getInfo()` + 事件 `tle-loader-state-change` 提供最新可更新版本，面板显示绿色「可更新 · vX」，Engine Hub 显示绿色小圆点。
- 用户可在面板主动「检查更新」或点击绿色按钮，后者交由 Loader 完成已校验源码安装与浏览器确认/安全回滚。正式版只静默检查，不在刷新时自动弹窗升级。
- 已有独立 TLE 与经校验的当前正式源码相同、尚无授权恢复时，面板可主动选择「启用 Loader 接管」。
- 不重新建立 Loader 面板/悬浮按钮，不修改移动端诊断按钮右上角、Top Layer、聊天工具、渐隐侠和兼容性规则。
- 无 Stable Loader 时显示连接指引；仅 Test Loader 时明确提示测试通道不等于正式通道。

仍需在 ST/TT 运行时验证从 0.3.202 更新至新版本的流程。
