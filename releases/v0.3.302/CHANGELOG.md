# v0.3.302 · 打码侠操作区文案校正

基于 Mask Hero Test Core v0.3.301 继续开发；仅更新独立 `mask-hero-test` 测试通道，不修改正式版 Core v0.3.294，也不修改 Stable Loader / Bootstrap。

## 打码侠操作区

- 操作顺序固定为：「应用」「卸除」「保存方案」「删除方案」「应用范围」。
- 仅将「卸除效果」缩短为「卸除」，将「应用范围设置」缩短为「应用范围」；「保存方案」「删除方案」保留完整名称。
- 「应用范围」默认收起；展开/收起只改变面板可见状态，不改变已选择范围。
- 默认应用范围为全部楼层；切换方案后设置面板重新收起。

## 楼层隐藏保护

- 保留 v0.3.300 的稳定消息身份匹配、不同非空 `gen_id` 冲突拒绝、模糊匹配保护，以及 TLE 原生隐藏/恢复的身份同步。
- 保留 v0.3.301 的手动恢复动态重定位：每次原生命令前重新读取聊天并按消息身份计算连续范围；目标消息被其他消息隔开时拆分执行。
- 每段原生恢复后重新读取聊天并核验目标身份确实恢复为隐藏状态；完成后才继续下一段。
- 身份缺失、重复、冲突或位置变化时停止，不使用旧楼层数字猜测目标。
- 异常解除保护仍只提示用户，不自动重新隐藏。

## 自动化验证

- 打码侠回归断言按钮名称、顺序、默认折叠状态和全部楼层默认范围。
- 保留隐藏楼层身份冲突、楼层插入、动态重算恢复范围、分段恢复、身份缺失安全中止及禁止自动重隐藏测试。
- 自动化源码验证不替代 ST / TT 实机验收。
