# TLE v0.3.221 — Test

## 配套侠
- 方案应用改为逐项执行；单项不可用不再中断其他项目。
- 跳过项目会在最终提示中列出名称与原因，区分连接配置、接口来源和模型列表未就绪等情况。
- 角色切换或脚本销毁仍会终止旧角色任务，避免把配置写入错误会话。

## 渐隐侠
- 增加对壁纸源祖先链 class/style/theme 属性的定向监听，覆盖主题通过继承样式或 CSS 变量更换壁纸的情况。
- 主题选择控件变更及壁纸图片 load 完成后触发一次合并同步。
- 不增加定时轮询；观察器仅监听壁纸祖先链的少量属性，更新仍通过单帧合并执行。

## 验收范围
- 需要在 SillyTavern 与 TauriTavern 分别验证。
- 重点验证 API 未连接、模型列表未加载、单项缺失时其他方案项目仍能应用。
- 重点验证切换多张壁纸、快速连续切换、切换主题后渐隐镜像是否同步，以及渐隐关闭后观察器是否释放。
