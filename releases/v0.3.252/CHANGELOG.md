# TLE v0.3.252 — Test

## 整理侠：分组操作入口常驻显示

- 修正 v0.3.251 的交互缺陷：此前未选中自定义分组时，重命名和删除按钮整个容器会被隐藏，界面上没有可见入口。
- 「分组操作：重命名 / 删除分组」现在始终显示在分组目录上方；未选中自定义分组时按钮置灰，选中后立即启用。
- 当前选中状态仍显示在「当前选中分组」一行；未选中时明确提示先点选下方分组。
- 按钮标题会说明当前操作对象；删除提示明确说明不会删除资源，只会将归属移回「未分组」。
- 不改变分组 ID、存储结构、资源归属、批量归组目标及原有删除确认流程；不追加 CSS 补丁，沿用酒馆原生按钮样式。
