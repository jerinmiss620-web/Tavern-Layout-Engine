# Core v0.3.296 · 打码侠 TEST 改进版

基于正式 Core v0.3.294 与首轮打码侠 TEST v0.3.295 继续开发；仅更新独立测试通道，不修改正式版 `latest.json` 或 `release-plan.json`。

## 本轮整改

- 名称替换改为直接更新 `.mes_block > .ch_name > .name_text` 实际节点，保留原节点与原始子节点片段；卸除时精确恢复，不再用隐藏原文加伪元素覆盖。
- 正文整体替换增加范围选择：全部楼层、最新 N 层、指定楼层范围；最新 N 层按当前聊天中 User / Char 消息的显示顺序计算，系统消息不计入。
- 保留单独楼层例外规则，并明确其优先级高于批量范围；范围外楼层会恢复原始 DOM，避免最新 N 层滚动后留下旧遮罩。
- 头像区增加明确的「上传图片」按钮；新增最近上传 6 张图片预览，可分别快速设为 User 或 Char 头像。
- 头像历史复用现有 IndexedDB，不另建存储系统；清理策略保留最近 6 张及所有方案正在引用的图片。
- 正文局部替换改为独立规则卡片；窄屏下查找、替换输入分行，正则与忽略大小写选项移至下一行，删除按钮固定在首行，不再争抢横向空间。
- 扩展纯逻辑与 DOM 回归测试，覆盖批量范围计算、名称节点原位替换与原始子节点恢复。

## 安全与边界

- 保留原始聊天文件只读边界、方案本地保存结构及独立测试 Loader。
- 旧方案缺少新增的 `bodyRule` 时自动归一为「不使用整体替换」，不破坏既有名称、楼层、局部规则与头像引用。
- 自动化回归通过不等同于 ST / TT 所有主题与设备的实机视觉验收；本轮仍需验证真实消息结构、移动端排版及头像历史复用。
