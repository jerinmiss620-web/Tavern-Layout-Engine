## 整理侠：分组管理区重新组织

- 新建分组继续使用「新分组名称」输入框与「新建分组」按钮，并允许窄栏下自然换行。
- 管理区明确显示「当前选中分组」；未选择时提示先点选下方分组目录中的目标分组。
- 重命名输入框改为「修改后的分组名称」，并明确标注「修改为」。
- 操作按钮改为「确认重命名」和「删除该分组」，按钮保留自然宽度，不强制占满整行。
- 明示删除语义：只删除分组关系，不删除资源；组内项目会移回「未分组」。
- 管理操作仍使用原有分组 ID 与原有数据结构；资源归属和分组存储格式不变。
