# Core v0.3.260 TEST · 配套侠全局世界书与默认方案入口优化

- **全局世界书纳入方案：** 保存当前配置时记录原生「全局世界书」多选框中全部已启用的书目；方案编辑器可多选，并保留当前无法读取的旧条目标记。v0.3.259 及更早版本的旧方案不会凭空补写历史状态；编辑时会显示「全局世界书（未保存）」，勾选该项并保存即可记录当前选择。
- **按清单同步：** 应用方案时，将所有可修改的全局世界书选项同步为方案保存的完整选择集合，而不是只逐本勾选，避免原方案以外的书目残留。
- **缺项透明反馈：** 方案中的世界书已不存在、被禁用，或当前宿主不允许修改时，逐项列出；其余可用项目继续应用，不因单本缺失中断整套方案。
- **TT 停靠面板：** 读取与应用优先使用 TauriTavern 原生面板运行时短暂挂载世界书控件，结束后恢复面板原有可见状态；无法取得控件时明确提示。
- **UI 主题诊断：** UI 主题原有快照与应用路径保留；新增 TT 主题控件未挂载、主题列表未就绪及绑定主题缺失等具体失败原因。
- **默认方案入口：** 普通配套方案列表和方案管理列表的每个方案均提供一个「设为默认 / 取消默认」按钮。设定另一方案时直接替换当前角色旧默认；取消时清除默认。
- **单一设置方式：** 移除方案编辑器中的重复默认复选框，编辑已有方案不会意外清除其默认状态；默认状态只通过方案列表按钮管理。
- **自动应用边界保持不变：** 仍只有真正切换角色时自动应用角色默认方案；Core 初始化、更新、刷新不会重放当前角色默认方案。启用日夜定时时，以当前时段方案优先。
- 不改动正式 Stable Core、Loader Runtime、Bootstrap；仅更新开发分支测试通道。

## 验收重点

1. 保存包含多本全局世界书的方案，确认编辑时所有书目均正确回显。
2. 手动应用该方案，确认全局世界书选中集合与保存时完全一致。
3. 在另一套方案中设置默认，确认旧方案按钮自动变为「设为默认」，新方案变为「取消默认」。
4. 分别在 ST 与 TT 测试主题切换、世界书控件未挂载和单本书目缺失时的提示。
5. 确认刷新/更新时仍不会强制重放当前角色默认方案；真正切换角色时按默认方案应用。
