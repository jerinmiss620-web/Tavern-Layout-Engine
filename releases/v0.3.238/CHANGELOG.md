# TLE v0.3.238 — Test

## 整理侠：修复右上角工具栏重复累积
- 根因：右上角同步、导入、导出按钮挂在整理侠标题栏；标题栏在抽屉关闭后仍保留，但每次重新打开整理侠都会再次 append 一套按钮。
- 创建分组管理器时改为对标题工具容器执行 replaceChildren，以唯一的一组同步/导入/导出控件替换旧内容。
- 关闭嵌入式整理侠管理器时清空标题工具容器，随本次管理会话释放控件。
- 不改动同步、导入、导出操作本身，也不通过 CSS 隐藏重复节点。

## 保留前版修复
- 配套侠：配置项逐项应用，不可用项跳过并报告具体原因。
- 渐隐侠：通过 DOM、主题祖先属性、样式表及加载事件触发按需镜像同步，不使用持续轮询。

## 验收重点
1. 连续从导航栏打开、关闭整理侠至少 10 次；右上角始终只出现一组“同步 + 导入 + 导出”按钮。
2. 验证同步 UI 主题分组、导入全部分组方案、导出全部分组方案均正常工作。
3. 打开整理侠后切换资源分类、筛选、刷新列表，不应重复生成标题工具栏。
4. 检查 v0.3.237 的配套侠与渐隐侠修复仍保留。
5. ST / TT / iPhone 运行验收待完成。
