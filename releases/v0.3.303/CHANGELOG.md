# Core v0.3.303 · 打码侠与隐藏楼层保护正式整合

基于正式 Core v0.3.294 之后的测试分支成果整理发布。保留现有 Stable Loader Runtime v0.3.6 与 Bootstrap v1.0.6。

## 打码侠

- 会话侠新增独立「打码侠」Tab，并由 TLE 引擎面板提供默认关闭的独立开关。
- 支持 User / Char 名称替换、正文整体替换、正文局部精确/正则替换，以及 User / Char 头像覆盖。
- 多套打码方案保存在本机；头像文件存放于独立 IndexedDB，不写入角色卡或聊天文件。
- 统一作用范围默认「全部楼层」，支持「最新 N 层」与「指定楼层范围」，统一约束名称、头像、正文整体/局部替换及单独楼层规则。
- 正文整体替换保留独立启用开关；单独楼层规则不得越过全局作用范围。
- 原始消息 DOM 可恢复；关闭功能、卸除效果、切换聊天或进入原生消息编辑时恢复显示层。
- 正则规则限制长度、嵌套量词及空字符串匹配；局部替换逐个文本节点执行，不跨富文本标签拼接，不让替换结果参与后续规则。

## 隐藏楼层保护

- 本机 IndexedDB 按角色/群聊及聊天文件身份隔离保存隐藏消息身份元数据与内容哈希，不保存正文副本。
- 优先使用稳定的 `extra.gen_id`；无稳定 ID 时使用发送者、名称、时间、正文哈希及相邻消息指纹回退。
- 不同非空 gen_id 冲突、重复候选、身份缺失或可信度不足时拒绝自动定位，不用旧 mesid 猜测。
- 每次原生恢复命令前重新读取聊天并按消息身份计算当前楼层；非连续目标拆分为多个连续区间。
- 每段恢复后重新读取并核验，再继续下一段；TLE 原生隐藏/恢复同步保护记录。
- 外部流程解除隐藏时仅提示用户；**默认不自动重新隐藏**。不写回原始聊天文件，不替代酒馆原生隐藏机制。

## 会话侠与布局修复

- 已隐藏楼层范围复制内容可直接粘贴到隐藏/恢复范围输入框；支持多种连字符，拒绝把多个不连续区间合并成一个范围。
- 打码侠字段基础样式不再默认设置 `flex: 1 1 140px`；该基准仅作用于横向工具栏和头像行，纵向正文替换 textarea 保留自然两行高度，消除异常大留白。
- 操作区顺序固定为「应用 / 卸除 / 保存方案 / 删除方案 / 应用范围」；应用范围默认折叠，默认范围为全部楼层。

## 安全边界与验证

- 打码仅作用于当前聊天的消息显示节点，不修改聊天文件、角色卡或消息源数据。
- 自动化测试覆盖打码规则、DOM 恢复、范围动态变化、隐藏身份匹配、歧义拒绝、非连续恢复及字段布局规则。
- 自动化回归不等于 ST / TT 全主题与设备实机视觉验收；仍需继续覆盖真实主题和设备。
