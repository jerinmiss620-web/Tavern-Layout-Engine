# Core v0.3.271 TEST · 记录预览底部配色修复

## 本次修正

记录预览卡片的底部渐变层原本虽然设置了白色文字，但日期、原生操作按钮和统计区域仍可能被酒馆主题的选择器覆盖，导致文字或图标在深色卡面上变暗。

- **统一颜色变量：** 在记录预览卡片底部覆盖层定义 `--freesia-gallery-overlay-color: #fff`，由日期、操作按钮和统计区域共同使用。
- **日期：** 强制使用覆盖层白色变量，并保留轻微透明度和文字阴影，避免继承原生 `.chatDate` 的深色文字。
- **操作按钮：** 置顶、重命名、删除图标统一使用白色；图标子元素继承按钮颜色；悬停或键盘聚焦时提高不透明度。
- **置顶状态：** 不再使用可能与背景冲突的 `SmartThemeQuoteColor`，已置顶与未置顶保持同一高对比度颜色。
- **底部统计：** 消息数量、文件大小及其图标统一继承覆盖层颜色，避免出现白色图标配黑色数字。
- **保持不变：** 卡片尺寸、2:3 头像比例、渐变曲线、文字位置、按钮尺寸、按钮行为和现有交互均不调整。
- **性能：** 仅调整原有 CSS 规则，不增加 JS、DOM 监听、轮询或图片处理；维护模块与 Core 内嵌模块保持逐字一致。

## 验收清单

1. 深色、浅色及纯白角色卡面下，日期均清晰可读。
2. 置顶、重命名、删除三个按钮始终保持统一白色。
3. 已置顶状态不受酒馆主题强调色影响。
4. 消息数量、文件大小及对应图标保持白色。
5. 切换酒馆主题后，记录预览底部颜色不发生意外变化。
6. 卡片布局、按钮尺寸、渐变和操作行为无回归。

**状态说明：** 本版本仅更新测试通道，待实际酒馆环境验收后再决定是否发布正式版。
