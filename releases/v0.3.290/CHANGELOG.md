# v0.3.290

## 配套侠：角色专属提示词条目状态（测试版）

- 为每个角色的配套方案增加可选的「提示词条目状态」配置。
- 采集并保存当前 Chat Completion 预设中可切换条目的稳定 identifier 与 enabled 状态。
- 不复制预设正文、条目内容、条目名称或排列顺序；预设本体仍是唯一数据源。
- 通过原生 Prompt Manager 开关控件恢复状态，适配 ST / TT 当前 Prompt Manager 的 identifier 与开关结构。
- 预设应用完成并等待 Prompt Manager 列表刷新后，再恢复角色专属状态。
- 预设未在配套方案其他字段中指定时，条目状态记录会自动定位并加载其绑定预设。
- 编辑正文、名称或拖动排序不会破坏匹配；新增条目保留预设当前状态并提示未纳入快照，已删除或无法匹配的条目单独跳过。
- 不增加提示词编辑器、预设管理器或预设副本；条目编辑继续使用酒馆原生 Prompt Manager 或用户已有脚本。

本版本仅发布到 feature 测试分支，正式 latest.json 仍保持 v0.3.289。
