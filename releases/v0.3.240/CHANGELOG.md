# TLE v0.3.240 — Test

## 信息站开关并入导航显示模式
- 删除「侧栏信息站设置」中的独立「启用信息站」复选框，不再读取或写入旧的 `tle.sidebarInfo.enabled` 总开关键。
- 信息站是否显示完全由导航栏显示模式决定：仅图标、图标 + 文字时关闭；图标 + 文字 + 信息站时开启。
- 首次使用时，所有信息站项目默认勾选「显示」和支持的「快切 / 跳转」；「当前角色世界书」没有快切选择器，继续提供跳转。
- 保留用户已保存的逐项设置。已有用户的显示、快切、跳转勾选不会因升级或切换导航模式而重置；新用户缺省项目采用全启用默认值。
- 设置说明改为面向首次使用者，明确总开关位置、自动关闭行为、默认勾选策略和角色世界书仅支持跳转的限制。
- 诊断状态与信息站刷新门控统一读取 `navigationMode === 'info'`，删除旧开关的事件处理和全局搜索设置索引入口。

## 不变项目
- 不改变信息站模块内容、快切弹窗、原生面板跳转行为及信息站宽度设置。
- 不改变全局搜索独立开关，也不改变导航模式本身的三种选项。
- 不重置现有 `tle.sidebarInfo.v1` 用户配置。

## 验收重点
1. 选择「极简：仅图标」和「标准：图标 + 文字」时信息站隐藏。
2. 选择「完整：图标 + 文字 + 信息站」时信息站开启，无需再勾选第二个开关。
3. 新用户的「显示」及可用的「快切 / 跳转」默认全选。
4. 老用户此前取消的任意选项在升级后仍保持取消；切换导航模式来回多次不会重置。
5. 「当前角色世界书」保持仅跳转，不显示不支持的快切选项。
