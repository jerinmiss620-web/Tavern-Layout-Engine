# Core v0.3.268 TEST · 记录预览底部信息区修正

## 本次修正

v0.3.267 的实机截图暴露了明确的布局错误：信息遮罩从卡片顶部铺满整张头像，文字与按钮落在人物面部；最近聊天概要也错误地放宽到 12 行。本版按原定设计纠正，不改变卡片主体方案。

- **头像：** 保留 2:3 竖版，图片完整铺满卡片。
- **信息区锚点：** 遮罩改为 `inset: auto 0 0`，只从卡片底部向上包裹内容；不再全卡覆盖。上半部保持干净，优先露出人物脸部和主体。
- **信息顺序：** 角色名 / 聊天数量；日期 / 原生置顶、重命名、删除图标；最近聊天概要；底部右对齐消息数与文件大小。
- **概要行数：** 严格限制最多两行（`-webkit-line-clamp: 2`），超出截断；容器不再使用弹性剩余高度，不允许显示成长段落。
- **渐变：** 渐变只存在于底部信息区，从透明过渡至深色，服务于文字识别；不在头像上半部叠加文字、按钮或整卡暗色蒙层。
- **原生操作：** 保留原生按钮尺寸、内边距、图标和点击行为，只移除底色、背景贴图、边框和阴影。
- **范围：** 只改 TLE 首页记录预览画廊卡片；角色管理页、最近聊天原始列表和记录详情页不改。
- **代码：** 直接替换 v0.3.267 的错误 CSS 与测试断言，不追加补丁；Core 内嵌模块与独立模块保持逐字一致。

## 验收清单

1. 2:3 头像上半部不显示角色名、日期、按钮或概要。
2. 信息区紧贴卡片底部，只占内容所需高度，且渐变不形成明显横向硬边框。
3. 名称 / 聊天数量同一行；日期 / 三个原生操作图标同一行。
4. 最近聊天概要最多两行，第三行及以后必须截断。
5. 消息数量与文件大小位于信息区最底部并右对齐。
6. 置顶、重命名、删除和打开最近聊天的点击行为保持正常。
7. 在 ST / TT PC 与移动端、明暗不同的头像和不同主题下实机验收。
