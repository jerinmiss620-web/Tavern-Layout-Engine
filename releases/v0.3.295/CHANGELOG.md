# Core v0.3.295 · 打码侠 TEST

基于正式 Core v0.3.294 开发，仅用于独立测试通道，不修改正式版 `latest.json` 或 `release-plan.json`。

## 新增：打码侠

- 会话侠新增第四个平级 Tab「打码侠」；TLE 引擎面板提供独立开关，默认关闭。
- User / Char 名称显示替换。
- 指定楼层正文整体替换。
- 正文局部精确匹配与正则替换；所有规则针对原始文本一次性匹配，替换结果不参与后续规则。
- User / Char 头像覆盖；图片存放在独立 IndexedDB，不写入角色卡或聊天文件。
- 支持多套本地方案的保存、切换、更新与删除。
- 关闭功能、手动卸除、切换聊天或进入原生消息编辑时恢复显示层；指针与键盘触发的原生编辑均会先卸除。
- 楼层整体替换保留原 DOM 节点片段；局部文字替换记录原始 Text 节点值，恢复时只回滚仍由打码侠持有的节点。
- 异步头像读取/上传及方案切换具备代次校验，避免过期异步任务在关闭或切换后重新应用旧方案。

## 安全与边界

- 不调用酒馆聊天保存 API，不修改 `context.chat`、角色卡或消息源数据。
- 正文局部匹配逐个 DOM 文本节点执行，不跨 HTML 标签拼接。
- 正则限制长度、嵌套量词及空字符串匹配，降低高风险表达式造成卡顿的可能。
- 本版本仍需 ST / TT 实机验收，自动化测试不代表所有主题头像与名称结构均已兼容。
