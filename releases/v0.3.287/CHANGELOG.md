# Core v0.3.287 · 角色记录、首页画廊与整理侠整合

## 本版更新

- 正式整合测试阶段的首页角色画廊与角色记录预览；保留酒馆原生角色头像预览区域，不另建一套角色管理系统。
- 角色记录详情支持角色资料、绑定世界书与聊天记录入口，减少重复操作按钮。
- 记录展示头像采用独立的显示约束，统一比例、圆角与边框表现；不改写聊天消息头像和酒馆原生角色列表头像。
- 整合头像高清兼容与主题圆角适配，避免主题切换后记录预览头像出现窄图、比例偏差或渐变边缘错位。
- 整理侠保留资源分组、批量操作、世界书绑定核对及独立查找替换入口，继续继承酒馆原生控件样式。
- 移动端记录详情在 820px 断点内，将 `--freesia-gallery-detail-main-gap` 设为 `5px`；头像列宽 104px、列间距 8px 保持不变。
- 本次间距修改直接合并进原有 CSS 自定义属性规则，不新增后置覆盖补丁。
