# Core v0.3.266 TEST · 记录详情文字导航重构

- **角色编辑导航：** 点击记录详情中的角色名称，调用酒馆原生 `selectCharacterById(..., { switchMenu: true })`，直接进入当前角色的管理 / 编辑界面。
- **世界书导航：** 点击绑定世界书名称，优先调用酒馆原生 `openWorldInfoEditor(worldName)` 打开指定世界书；对未暴露该模块接口的 TT 构建，回退到原生世界书抽屉与选择器。
- **聊天文件导航：** 移除「聊天文件」独立按钮，将「X 个聊天」改为文字导航入口，打开当前角色的聊天文件列表。
- **描述区精简：** 移除「角色描述」标题文字及其所在行；头像旁角色名 / 世界书同一行，下一行直接显示角色描述正文。
- **按钮清理：** 移除「详情/管理」按钮，不再以按钮外观包装三个导航入口；使用主题继承的文字链接样式和键盘焦点提示。
- **保留 v0.3.265：** 首页版本号位置、首页记录预览开关、头像伪元素 / border-image 兼容选项、详情标题左右对齐、首页最近聊天信息区垂直居中均保留。
- 本版仅更新测试通道；不修改 Stable Core、Stable Loader Runtime 或 Bootstrap。

## 验收重点

1. 点击角色名称，打开当前角色的原生管理 / 编辑界面；不打开错误角色。
2. 点击绑定世界书名称，打开该角色实际绑定的那本世界书，而不是只打开世界书列表。
3. 没有绑定世界书时不显示可误点的空链接；绑定记录失效时给出明确提示。
4. 点击「X 个聊天」，进入当前角色的聊天文件列表；返回按钮回到该角色记录详情。
5. 页面不再显示「详情/管理」按钮和「聊天文件」独立按钮。
6. 页面不再显示「角色描述」标题行；描述正文直接位于角色名 / 世界书行下方，头像与资料区既有等高布局保持。
7. 角色名左对齐、世界书右对齐；手机窄屏不出现重叠，长名称按现有省略规则处理。
8. 保留聊天文件搜索、打开、置顶、重命名、删除等原有操作。
9. ST / TT PC 与移动端主题兼容仍需实机验收；自动化结构测试不能替代真实界面检查。
