# TLE v0.3.204 TEST — 旧 Test Loader 的更新入口兼容

## 为什么旧版本看不到提示
- 旧 Test Loader 0.3.0 从缓存启动的 Core v0.3.198 没有新版本显示和绿色按钮。必须先通过已安装 Loader 成功更新旧代码，GitHub 清单不能直接修改已运行的旧界面。
- v0.3.203 的新按钮只识别 Stable Loader 0.3.1，漏掉已安装的 Test Loader 0.3.0，本次兼容补足。

## 修改
- 保留优先使用 Stable Loader 的静默检查、绿色更新徽标、一键安装与授权接管。
- 未安装 Stable Loader 时，可使用现有 Test Loader：显示「Test Loader · 测试通道」「检查／安装更新」。此旧版 API 会在检查后主动请求确认，并非静默检查；仅用户点击按钮才由 TLE 调用。
- 显示运行中真实版本以及已验证的候选版本，不将仅恢复缓存误称为成功更新。
- 保留双楼层输入、单层同值提示、会话侠聊天操作、渐隐侠及 TT ChatSurface，诊断按钮保持右上角及 Top Layer 回退。

## 发布记录与脚本 info
- 独立 `CHANGELOG.md` 记录版本功能、修复和兼容限制，保留历史。
- 安装脚本单行 `info` 明确包含简介、使用方式、注意事项、作者，不在信息字段内写多行转义文本。
- 本版本先走测试通道，ST/TT 上的旧 Loader 升级流程仍需实测。
