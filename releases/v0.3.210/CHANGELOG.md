# TLE Core v0.3.210 — 移动端分组管理紧凑化

## 快速切换分组管理
- 将标题栏的「导入方案文件」「导出全部分组」由文字按钮改为文件导入 / 文件导出图标，**与标题和关闭按钮同一行**，不再在手机端另占一整行。
- 图标按钮保留原回调、全分类导入导出、确认机制；加入 `title` 提示和明确的 `aria-label`，图标标为装饰内容。按钮使用固定 36px 宽高与原有 `menu_button` 风格。
- 直接修改原有弹窗标题 Flex 规则：禁止旧手机布局将操作区换到下一行，标题可以压缩省略，关闭按钮也固定为紧凑方形。
- 「读取主题管理分组」改为主题分类分组筛选条**右侧的「↻ 同步」小按钮**；只在「当前 UI 主题」显示，分组筛选标签继续支持横向滚动。所有主题导入数据处理、覆盖前确认和分类隔离逻辑保持不变。
- 移除标题下方重复的全局备份长说明，保留一行简短提示与详细 `title`，减少占用纵向空间。
- 管理分组展开后，移动端新分组名称输入框独占一行，创建/重命名/删除在下一行等宽排列，避免极窄屏幕挤出边界。
- 不再在打开管理弹窗时自动聚焦搜索框，避免 iOS/Android 非用户主动操作就弹出键盘。
- 在原有 CSS 和 UI 构建函数中直接整合修改，清理废弃的 `.tle-quick-backup-hint` 与旧手机换行规则，不打补丁。

## 不变范围
- TLE Core 已有自动更新折叠、楼层侠双列提示行、楼层侠对齐、导航兼容性选项及 TT 聊天虚拟化功能全部保持。
- Loader v0.3.4 / Bootstrap v1.0.2 不改动，仍可自动取得正式 Core 新版本。
- GitHub 代码回归需覆盖移动端布局 CSS、读写按钮 aria-label、主题导入原确认逻辑与源码包一致性。真实 TT/iOS 视觉仍需用户实测。
