# Core v0.3.273 TEST · 记录预览底部空间微调

## 本次调整

根据实机截图反馈，进一步压缩记录预览卡片底部布局，让日期获得完整显示空间，同时收紧覆盖层和统计行。

- **日期行：** `gap: 0`，移除日期与按钮组之间额外的 6px 间距；日期继续弹性占用剩余宽度。
- **底部覆盖层：** 内部纵向 `gap: 2px`，左右及底部 padding 调整为 5px，上方渐变留白保持 30px。
- **统计行：** 改为 `align-items: end`，移除强制设置的 `line-height: 0.85`，不再额外压缩行高。
- **聊天数量：** 字号改为 `clamp(10px, 0.72em, 12px)`，避免窄卡片上文字过小，也避免宽卡片上字号过大。
- **保持不变：** 24 × 24px 原生操作按钮、按钮点击行为、统一白色配色、头像比例、卡片圆角和渐变色阶。

本次只整合修改已有 CSS，不增加 JavaScript、监听器、轮询或额外渲染逻辑。仅更新测试通道，待实机验收后再决定是否进入正式版。
