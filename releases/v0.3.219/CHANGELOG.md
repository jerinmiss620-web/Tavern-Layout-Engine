# v0.3.219 · 整理侠原生删除权限校正

- 修正批量删除资源范围：User 身份、UI 主题加入可删除资源，统一调用酒馆原生删除能力；User 身份通过 `/persona-delete ... silent=true`，UI 主题通过 `/api/themes/delete`。
- 删除权限只依据酒馆原生是否提供删除能力：角色卡、全局世界书、预设、推理格式、User 身份、UI 主题开放批量删除；API/模型等不可删除运行配置仅允许搜索，不出现在资源管理分类中。
- 保留全部既有 `tle.quickGroups.v2` 分组数据及全量备份数据；API 等搜索专用分类的旧分组数据仍保留于本地存储和导入/导出，不会因本次升级丢失。
- 移除角色卡批量删除前必须退出会话的额外限制；调用原生删除函数，由酒馆原生逻辑处理当前会话；`deleteChats: false` 继续保留聊天记录。
- 移除“至少保留一个预设/推理格式”的人为限制；GUI 预设继续受酒馆原生保护，混合选择时只跳过该保留项。
- UI 主题删除后自动刷新酒馆，以同步酒馆内部主题列表与已删除文件。
- 批量删除仍采用统一二次确认、逐项结果核验，并清理已删除资源的分组归属；删除分组本身仍只解除分组归属，不删除资源。
- 整理侠唯一入口、原全局搜索能力、共享搜索框、快切分组数据结构与导入/导出保持不变；正则继续由正则侠管理。
- Bootstrap v1.0.6、Loader Runtime v0.3.6 和更新链不变；无需重新导入 Bootstrap。
- 自动化 CI 与实机验证状态以 `VALIDATION.md` 为准；未完成的 ST/TT 实机验收不宣称通过。
