# Core v0.3.267 TEST · 记录预览头像内信息卡重构

- **卡片比例：** 首页角色预览卡统一改为宽 2、高 3（`aspect-ratio: 2 / 3`），头像填满整张卡片。
- **信息布局：** 采用方案二：第一行左侧角色名、右侧聊天数量；第二行左侧日期、右侧三个图标操作；中部最近聊天概要使用剩余空间；右下方显示消息数与文件大小。
- **操作按钮：** 继续克隆最近聊天的原生置顶、重命名和删除按钮，保留原生尺寸、内边距、图标和点击行为；仅移除按钮底色、背景贴图、边框与 box-shadow，不覆盖宽高或 padding。
- **卡片所有权：** 自建角色卡不再带 `.recentChat` 类，不继承最近聊天原生卡片的外层背景、间距和布局；头像节点与操作按钮仍复用原生 DOM。
- **概要区域：** 最近聊天文字左对齐、顶部起排，在卡片剩余高度内自然换行，最多显示 12 行；右下统计信息横向排列并右对齐。
- **渐变遮罩：** 仅在头像上叠加轻量上下渐变与文字阴影，辅助不同明暗头像上的文字识别；不使用 backdrop-filter、动画或额外图片资源。
- **CSS 清理：** 删除旧的头像下方三段式布局、旧的 latest 区域规则和操作按钮尺寸变量；新结构直接替换原规则，不叠加补丁。
- **范围：** 只影响 TLE 首页「记录预览」画廊卡片；酒馆原生角色管理页、最近聊天原始列表、记录详情页（仍为 3:4 头像）不改动。
- **通道：** 仅更新 `channels/test.json`；正式 Stable Core、Loader Runtime 与 Bootstrap 不变。
