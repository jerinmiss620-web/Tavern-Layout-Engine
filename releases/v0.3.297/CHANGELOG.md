# v0.3.297 · 会话侠隐藏范围智能粘贴

基于测试 Core v0.3.296 继续开发；仅更新独立 Mask Hero Test 通道，不修改正式版 v0.3.294。

## 本轮优化

- 「已隐藏楼层范围」复制出的单段区间，可直接粘贴到隐藏 / 恢复楼层的起点或终点输入框。
- 自动识别 ASCII 连字符、短横线、en dash、em dash、全角连字符与 Unicode minus，并拆分填入两个输入框。
- 复制内容为单个楼层编号时，自动将相同编号填入起点和终点。
- 多个不连续范围不会被错误合并成一个连续区间；倒序范围和超出安全整数范围的内容会拦截并提示。
- 保留现有双输入框、原生 /hide 与 /unhide 执行方式，不增加额外按钮或第二套状态。

## 验证边界

- 新增范围解析与双输入框粘贴专项回归测试。
- 自动化测试通过不等同于 ST / TT 实机验收；仍需验证复制、粘贴及输入框清除按钮在实际主题和移动端上的行为。
