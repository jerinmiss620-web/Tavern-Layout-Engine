# TLE v0.3.202 — Stable Release

## 核心功能与版本整合

- 基于完整的 v0.3.198 功能基线以及 v0.3.199–0.3.201 测试修正版，保留现有导航布局、快速切换、侧栏信息站、楼层侠、会话侠、回底侠、渐隐侠、折叠侠与引擎体检仪。
- 楼层侠继续采用独立楼层跳转 + 双范围数字输入 `起点 - 终点`，分别触发隐藏/恢复斜杠命令；提示只操作单层时两框填写相同数字。
- 会话侠提供可选的原生「新建聊天」「关闭聊天」「管理聊天文件」操作，不修改酒馆原生菜单及确认机制。
- 继承 v0.3.198 的导航图标与文字区域分离命中、pointerdown/click 事件路径与宿主诊断信息。

## 导航兼容修复（仅主动启用）

- 在「兼容性修复 → 修复侧边导航按钮宽度与图标可见性」中，用稳定的非零按钮槽位替代旧的 `width:fit-content` 方案，避免由空伪元素造成原生点击宽度坍缩、文字挤压或右对齐。
- 仅当导航兼容修复开关启用时，对原生 `.drawer-icon` 使用可调的 `opacity:var(--tle-nav-icon-opacity,0.7)!important`；滑块支持 40%–100%，默认 70%，实时生效并记忆上次设置。普通主题默认保持自身透明度，不受 TLE 干预。
- 保留主题的原生 `::before` 图标贴图与背景规则，兼容修复关闭后撤销额外透明度变量。

## 代码整理与诊断保护

- 删除已经失效/被替代的全局图标透明度规则、`width:fit-content`、文字模式 15px 双边距和旧单框范围文本；复用原有兼容开关与 CSS 规则，不增加重复补丁。
- 已扫描顶层函数声明，未发现可以安全删除的孤立函数；对动态调用、卸载恢复和第三方宿主耦合的逻辑不进行无依据删减。
- **诊断按钮继续固定于移动端右上角**：`syncDiagnosticButtonPosition`、`createDiagnosticButton`、`watchDiagnosticButton` 以及相关 CSS 均与上一测试版逐字一致。保留 Top Layer 优先 / document root 固定定位回退，不重引入右下角不可见的问题。
- 渐隐侠/TT ChatSurface、原生会话快捷操作和双范围输入命令执行的核心实现逐段比较未改动。

## 验证与范围

- JS 静态语法、源码与脚本导入包一致性及指定旧代码清理检查通过。
- 透明度兼容开/关、滑动、保存、重新开启、上下限行为；单层/多层隐藏恢复及非法输入拦截均通过独立逻辑回归。
- 此前维护者已在异常主题下实测原生导航点击与布局修复有效；本次透明度滑块迁移到兼容性设置后的完整 ST/TT/手机端交互未进行全覆盖真机验收，不将静态检查等同于全部宿主验证。
