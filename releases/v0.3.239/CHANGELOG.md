# TLE v0.3.239 — 正式发布

## 整理侠 PC 三栏分隔线重构
- PC 端「资源类型 / 分组目录 / 资源列表」保留三栏结构，移除三块独立的半透明底色面板，改用两个语义化 `hr` 元素作为纵向分隔线。
- 通过 `writing-mode: vertical-rl` 与逻辑边框方向呈现纵向主题分隔，不使用旋转变换；分隔线跟随酒馆 `--SmartThemeBorderColor`。
- 1000px 及以下隐藏竖向分隔线，移动端原有单栏布局不变。

## 整理侠标题工具栏重复挂载修复
- 标题工具栏由追加改为幂等替换，打开整理侠时只保留一组同步、导入、导出按钮。
- 关闭嵌入式管理器时清理本次管理会话创建的标题工具，连续打开/关闭不再累积重复按钮。
- 不通过 CSS 隐藏多余按钮，不改动同步、导入、导出功能本身。

## 配套侠部分应用与错误提示
- 配套方案改为逐项应用；单项缺失、不可用或原生控件未就绪时跳过该项，继续应用其他可用配置。
- 对连接配置、接口来源、模型列表分别说明缺失原因；全部失败时明确提示，不再静默失败或显示假成功。
- 角色切换与脚本卸载仍按取消处理。

## 渐隐侠壁纸镜像同步
- 壁纸源祖先节点的主题属性、样式表变化、主题选择器变更及图片加载完成时，按需触发镜像同步。
- 同一帧内合并刷新，不使用持续轮询；关闭渐隐侠或卸载 Core 时释放观察器。

## 更新链
- Core 更新至 v0.3.239。
- Loader Runtime v0.3.6 与 Bootstrap v1.0.6 不变；继续使用原有自动更新链。
