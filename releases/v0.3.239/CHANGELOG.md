# TLE v0.3.239 — Test

## 整理侠 PC 三栏分隔线重构
- PC 端「资源类型 / 分组目录 / 资源列表」保留三栏结构，移除三块独立的半透明底色面板，避免大色块把内容切割成三张卡片。
- 在三栏之间插入两个语义化 `hr` 元素，作为纵向分隔线。
- 使用 `writing-mode: vertical-rl` 将 `hr` 的逻辑块起始边映射为物理竖边，并以 `border-block-start` 跟随酒馆主题的 `--SmartThemeBorderColor`；不使用旋转变换，避免横向占位尺寸与纵向视觉尺寸不一致。
- 分隔线仅在 PC 三栏布局显示；1000px 及以下隐藏，移动端仍使用原有单栏布局。
- 保留三栏独立滚动、列宽比例、资源筛选、分组管理、批量操作和标题工具栏行为。

## 保留前版修复
- v0.3.238：整理侠标题工具栏改为幂等挂载，打开/关闭不会累积同步、导入、导出按钮。
- v0.3.237：配套侠逐项应用可用配置，对不可用项目跳过并说明原因；渐隐侠按需响应壁纸/主题 DOM 变化刷新镜像，不使用持续轮询。

## 验收重点
1. PC 浅色与深色主题下，三栏不再出现独立色块底板；两条竖向分隔线从工作区顶部延伸到底部。
2. 切换主题后，分隔线颜色跟随 `--SmartThemeBorderColor`。
3. 1000px 以下分隔线不显示，原移动端单栏排布与滚动行为不变。
4. 连续从导航栏打开/关闭整理侠，标题工具栏仍只有一组同步、导入、导出按钮。
5. ST / TT / iPhone 实机视觉验收待完成。
