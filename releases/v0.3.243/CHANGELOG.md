# TLE v0.3.243 — Test

## 整理侠搜索方式改为常驻双按钮模式切换
- 移除「资源名称 / 查找与替换」原有 radio / checkbox 外观控件，不再用单选或多选输入框表达模式。
- 改为两个始终并排显示的普通按钮：资源名称、查找与替换。
- 当前模式通过按钮的选中底色、主题色边框和字重表达；另一按钮保持可见，点击即切换。
- 使用普通 button 与 `aria-pressed` 状态，不使用隐藏输入框，也不隐藏未选中的模式。
- 保留原搜索模式切换、搜索词暂存、内容规则加载、扫描与替换逻辑。

## 同时保留 v0.3.241 / v0.3.242 修复
- 配套侠初始化/更新/重载不重放当前角色默认方案。
- 日夜定时按角色记录时段令牌；保留错过边界后的恢复、手动覆盖、逐项部分应用及缺项原因提示。
- v0.3.242 的搜索方式单选方框样式被本版双按钮交互完整替代。

## 不变项目
- 不修改配套侠、信息站、资源分组、批量删除及其他功能逻辑。
- 不修改 Loader Runtime、Bootstrap、正式 Stable Core。
- 不追加补丁式 CSS；按钮样式直接整合进 Core 原有 createStyle 样式块。

## 验收重点
1. 两个模式按钮始终同时可见，不再出现方框或圆形单选/多选标记。
2. 当前模式有明确的底色与边框区别；另一模式保持普通按钮外观。
3. 点击任一按钮可切换，切换后两个按钮的 `aria-pressed` 状态同步更新。
4. 切换后搜索框、替换输入框、扫描按钮及原有功能正常。
5. PC、移动端及不同 UI 主题下按钮不换行、不溢出，选中态颜色可辨识。
6. v0.3.241 配套侠初始化保护及日夜定时恢复不回归。
