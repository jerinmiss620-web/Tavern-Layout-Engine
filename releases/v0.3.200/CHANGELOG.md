# TLE v0.3.200 TEST — 楼层侠范围双输入与会话侠快捷操作可见性

> 测试分支独立手动导入；main 和稳定频道保持不变。

## 楼层侠
- 修正此前误解：不是“跳转一行 + 范围一行=两个输入框”；正确方案是在**楼层范围这一行**设置“起点输入框 - 终点输入框 【隐藏】【恢复】”，跳转仍有自己的单独输入框。
- 两个范围框均为数字输入模式、独立清除按钮；提交时自动拼为 `/hide x-y` 或 `/unhide x-y`，不需要手工输入连字符。单楼层可以输入相同起止值，例如 90 和 90 自动生成 `90-90`。
- 保留空值、非数字、整数安全、起点不大于终点、最后楼层越界等校验；执行时禁用当前行全部操作，避免重复提交。
- 窄屏采用两侧 `minmax(0,1fr)` 和中间固定连字符，仍能排列两枚范围按钮。两个输入框各自的清除按钮仅清除其对应字段。

## 会话侠
- 标题栏「新建」「关闭」「文件」三个原生操作改为**默认开启**，保留「在会话侠标题栏显示聊天快捷操作」设置，用户明确关闭后仍尊重存储值。
- 保留原生 SillyTavern 菜单 `option_start_new_chat`、`option_close_chat` 和 `option_select_chat` 调用及原有回退逻辑。
- 若旧版本曾将此选项持久化设置为 false，则需要在 TLE 设置中重新勾选；不覆盖用户明确禁用的持久设置。

## 保留功能与安全
- 基于完整 v0.3.199 TEST 版本，保留 0.3.198 的图标点击诊断、会话侠、楼层侠、渐隐侠及 TT ChatSurface 支持。
- 保留上一轮已验证的原生导航 44px 点击槽位、文字左对齐、图标 opacity:1 兼容修复。
- JS 静态语法、功能存在性和源码/导入包一致性已检查；实际 ST/TT 运行回归仍需测试。
