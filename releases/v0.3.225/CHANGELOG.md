# Core v0.3.225 · 整理侠 PC 三栏资源工作区

## PC 宽屏三栏布局

- PC 宽屏（视口宽度大于 1000px）整理侠改为三栏：左侧「资源类型」、中间「分组目录」、右侧「资源列表」。
- 左栏保留现有可管理资源类型；中栏显示「全部项目 / 未分组 / 各命名分组」及项目数量；点击后只筛选右栏资源列表。
- 搜索框放入右侧资源栏；世界书绑定状态筛选、批量目标分组、批量选择、删除和刷新等操作继续位于资源列表侧。
- 左侧类型列表、中间分组目录、右侧资源列表各自独立滚动，不互相挤压。

## 移动端保持单栏

- 1000px 及以下不启用三栏网格；同一组界面节点展平回单栏纵向流程，保留原有窄屏分类、分组筛选与批量操作。
- 不新增移动端管理器，不改写现有分组数据结构，也不改变酒馆原生抽屉尺寸和滚动所有权。

## 原有能力保持

- 继续复用现有资源目录、分组存储、搜索过滤、世界书绑定筛选、懒加载扫描、批量删除与安全确认。
- 全部分组方案导入/导出和 UI 主题分组同步保留。
- 关闭嵌入式管理器时，将搜索框恢复到原抽屉位置，避免关闭后丢失搜索控件。
