# TLE v0.3.242 — Test

## 整理侠搜索方式改为 checkbox 外观的单选控件
- 「资源名称 / 查找与替换」继续使用同一组原生 `radio`，保留单选互斥、原生 change 事件与键盘操作。
- 将容器语义明确为 `radiogroup`，选项保留 label 关联。
- 仅调整视觉层：圆形原生单选标记改为 14px 方框与勾选符号；焦点、悬停和选中状态沿用酒馆主题色变量。
- 不使用 checkbox 加 JS 互斥，不改搜索模式切换、扫描、替换及选择状态逻辑。

## 同时保留 v0.3.241 配套侠修复
- TLE 初始化/更新/重载不重放当前角色默认配套方案。
- 首次升级只建立日夜时段基线；后续跨时段恢复、手动覆盖、逐项部分应用和缺项原因提示继续保留。

## 不变项目
- 不修改配套侠、信息站、资源分组、批量删除及其他功能逻辑。
- 不修改 Loader Runtime、Bootstrap、正式 Stable Core。
- 不添加补丁式 CSS；方框单选样式直接整合进 Core 原有样式定义。

## 验收重点
1. 两个选项显示为方框勾选样式，而不是圆形单选点。
2. 任一时刻只能选中一个选项；点击后原有搜索模式切换正常。
3. Tab 可聚焦，方向键可在同组原生 radio 间切换，焦点轮廓清晰。
4. 在不同 UI 主题下，边框、勾选标记与焦点色能继承主题变量。
5. v0.3.241 的配套侠初始化保护与日夜定时恢复不回归。
