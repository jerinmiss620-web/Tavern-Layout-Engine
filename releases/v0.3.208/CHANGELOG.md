# TLE Core v0.3.208 — 楼层侠列宽与兼容选项说明

## 楼层侠横向留白修复
- 修正之前楼层侠“楼层跳转 / 楼层范围”的标签列固定为 `5.8em`，对仅四个汉字的文字预留过宽位置的问题。
- 在原有 `.tle-chat-tools-action` 规则内，将第一列改为 `max-content`，控制区继续使用 `minmax(0, 1fr)`；标签自身 `width: max-content` 并清理不必要的边距，布局按实际文字宽度排列。
- 保留范围输入框、跳转/隐藏/恢复按钮、两框提示文字位置和移动端输入空间，不增加 CSS 补丁或 `!important`。

## 兼容性选项说明
- “修复侧边导航按钮宽度与图标可见性”是手动启用的主题兼容修复，**不是所有主题必开的功能**。
- 开启后会强制调整原生导航按钮和图标的尺寸与透明度；在本来正常的主题中也可能造成图标和文字错位。这属于启用强制兼容规则的预期副作用，不应算作基础布局失效。
- 已直接修改面板原有选项说明，明确正常主题应保持关闭。
- **不修改原有兼容修复选择器及图标透明度设置**，避免影响确实依靠它恢复隐藏图标的特殊主题。
