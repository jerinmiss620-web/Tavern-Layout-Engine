# TLE v0.3.293 · TEST ONLY

> 基于现有 Organizer 测试频道 v0.3.292 修复配套方案保存界面的全局世界书多选控件；不修改正式版 `latest.json`。

## 配套侠：全局世界书选择器

- 移除可见原生多行列表框，避免世界书选项撑开保存方案面板
- 改为折叠式下拉复选清单，每本世界书独立勾选，不再依赖 Ctrl / Shift
- 已保存但当前未读取的世界书继续显示为已选、禁用项，避免编辑后意外丢失
- 保留原生多选数据源及 `selectedOptions` 保存路径，不改变方案数据结构
- 支持浏览器 Popover 时使用顶层弹出层，避免被保存面板滚动容器裁切；不支持时回退为面板内下拉

## 验证范围

- 下拉展开/收起、逐本勾选、摘要数量同步、点击外部关闭与 Escape 关闭
- 已保存缺失世界书的保留、禁用状态与重新启用行为
- 原生多选数据源、方案保存读取路径与世界书应用逻辑保持不变
- 自动化回归通过后，再进行 SillyTavern / Tavern 实机验收；自动化测试不替代真实宿主验收
