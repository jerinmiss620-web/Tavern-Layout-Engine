# Core v0.3.223 · 全局搜索与整理侠分离 / 世界书快速筛选

## 入口拆分

- 恢复工作区顶栏的独立「全局搜索」按钮，点击打开原有全局搜索弹窗。
- 全局搜索保留原索引、搜索框、结果定位、清空和刷新行为。
- 全局搜索弹窗增加「整理侠」跳转入口；跳转时关闭搜索弹窗并打开整理侠，不把资源管理塞进搜索界面。
- 整理侠继续作为侧边栏第十个原生形态抽屉，拥有独立 `.drawer-content`、资源筛选输入框、分组和批量管理界面。
- 全局搜索与整理侠分别管理界面状态；全局搜索开关只控制搜索按钮，不会隐藏整理侠。
- 全局搜索与替换的后续整合不包含在本版本，留待 Codex 单独处理。

## 世界书快速筛选

新增快速筛选：

- 全部
- 已绑定：存在至少一张现存角色卡的主要绑定或额外绑定。
- 未绑定：没有角色卡绑定，也没有已知遗留关联；若仍有未加载角色卡，暂不将未知项目判定为未绑定。
- 疑似孤儿：存在指向已不存在角色卡的额外绑定记录；若该书同时仍绑定其他现存角色卡，显示「含遗留关联」。
- 全局启用：当前加入全局启用列表的世界书。全局启用与角色卡绑定是独立状态，可以同时出现在「已绑定」或「未绑定」筛选中。

列表保留名称搜索、分组筛选、多选、分组管理和批量删除。全局启用状态单独显示标记。

## 孤儿识别边界

酒馆未必保留已删除角色卡的主要世界书引用。若唯一的主要绑定只存在于已删除角色卡文件中且没有其他残留元数据，TLE 无法还原原关联，会显示为「未绑定」供人工核对。疑似孤儿只依据仍存在但无法匹配现存角色卡的额外绑定记录。懒加载角色卡未扫描前，未知绑定保持「待核对」。
