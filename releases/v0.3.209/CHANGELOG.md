# TLE Core v0.3.209 — 楼层侠提示行及主题分类分组入口整理

## 楼层侠提示文字
- 在原有 `#tle-chat-tools-panel .tle-chat-tools-range-help` CSS 规则中，将 `grid-column: 2 / -1` 改为 `1 / -1`。
- 提示文字从网格第一列开始横跨两列，与楼层跳转和楼层范围输入行对齐，避免仅占第二列造成的多余换行。
- 保持 v0.3.208 的 `max-content` 标签宽度、输入框及按钮尺寸，不追加覆盖补丁或新的 `!important`。

## 快速切换分组管理
- 原先放在弹窗顶部、与全部分组导入导出并列的「读取主题管理分组」改为**仅在「当前 UI 主题」分类显示**，位置在该分类的分组筛选和管理操作之间。
- 该入口只关联 UI 主题，并仍调用原本的 `importThemeManagerGroups()`，保留确认弹窗、主题分组替换和已有分组赋值逻辑；不会对其他快切分类操作。
- 顶部只保留全局「导入方案文件」「导出全部分组」；说明文案同时更新，避免用户误把主题导入当作全部分类操作。
- 复用原有按钮及弹窗的排版体系，在现有样式段调整布局、隐藏状态，并清理旧位置的按钮，不追加末尾补丁。

## 不变范围
- TLE Loader v0.3.4 与 Permanent Bootstrap v1.0.2 完全不变，无需重新安装。
- 不修改导航兼容修复、Theme Manager 分组数据格式、导入导出方案的 schema、楼层侠斜杠命令、右上角诊断按钮、TT ChatSurface、渐隐侠或最近聊天。
