# TLE v0.3.237 — Test

## 配套侠：部分可用项继续应用
- 方案应用改为逐项处理：某一项缺失、不可用或控件未就绪，不再中断其他配置项。
- 连接配置、接口来源、模型分别给出缺失原因；模型列表未加载时会明确提示 API 可能未连接或服务商尚未返回模型。
- 结果通知列出每个跳过项目及原因；全部失败时明确报告“未能应用任何项目”，不再显示成功。
- 只有至少一项成功应用时才记录手动保持，避免零成功时错误锁住日夜定时方案。
- 角色切换和脚本卸载仍作为取消处理，不会被误报成普通缺项。

## 渐隐侠：按需同步壁纸镜像
- 保留原有 #bg1 自身与父节点变化观察。
- 新增对 #bg1 祖先链 class/style/theme 属性变化的监听，覆盖壁纸通过继承样式或 CSS 变量变化的情况。
- 新增对 head 中样式表节点增删、href/rel 等属性变化及样式内容变化的监听。
- 主题选择器变更、样式表加载完成、渐隐区域内壁纸图片加载完成时触发同步。
- 所有触发仍由 requestAnimationFrame 合并，同一帧只执行一次镜像刷新；不增加 setInterval 或持续轮询。
- 诊断信息增加 themeObserverPresent，便于确认主题观察器是否建立。

## 验收重点
1. 配套侠：分别测试 API 未连接、模型列表未加载、某个预设/推理格式/主题已删除等情况；确认其他可用项仍然应用，通知逐项列出跳过原因。
2. 渐隐侠：测试更换壁纸、快速连续切换主题、切换主题 CSS、图片延迟加载；确认镜像及时更新且不残留旧图或错位。
3. 确认关闭渐隐侠及卸载 TLE 后，壁纸观察器全部释放。
4. 本版本已更新测试通道；仍需在实际 SillyTavern / TauriTavern 与 iPhone 环境完成运行验收。
