# TLE v0.3.292 · TEST ONLY

> 基于 main / Core v0.3.291 整合，不修改正式版 latest.json。此版本仅进入测试通道。

## 配套侠：角色专属预设条目方案

- 每个角色独立保存稳定条目标识与启用状态，不复制预设正文、名称或顺序
- 预设条目改名、编辑正文或调整顺序后，仍按 identifier 匹配
- 新增条目保持原生状态；只有用户显式重新读取并保存方案后才纳入
- 删除、锁定条目分别提示；可用条目继续独立应用
- 共享全局预设时，切换角色前先恢复原始预设的条目开关状态
- 原始状态无法安全恢复时，阻止新方案继续应用，避免角色状态串用或污染原生预设
- 原生提示词管理器保存前恢复预设基线，恢复不安全时取消保存

## 导航兼容修复

- 保留 Flex 图标容器与双轴居中修复
- 图标选择器兼容包装层，不再只匹配直接子元素
- 闭合与打开状态统一应用透明度
- 恢复主题隐藏的内部 glyph 与 `::before` 贴图可见性

## 验证范围

- 角色专属条目标识匹配、角色隔离、预设编辑/排序、增删条目及基线恢复专项回归
- 导航图标闭合/打开状态、包装层、内部 glyph、透明度及样式注入专项回归
- GitHub Actions 全量自动化通过后再进行 ST / TT 实机验收；自动化测试不替代真实宿主验收
