# TLE Core v0.3.212 — 配套侠与可选功能包

## 配套侠正式内置
- 纳入配套侠：可以按角色保存、管理和关联配置方案，联动预设、模型、推理格式与 UI 主题，并按计划自动切换。
- 配套侠属于 TLE 内置功能，无须额外下载安装；切换 UI 主题时可以与独立的「主题绑定壁纸」脚本协作。

## 正式可选功能包
- 在 TLE 控制面板新增「可选功能包」，提供状态检测、安装并启用、启用、停用、卸载、刷新状态和「··· 更多」使用说明。
- **Freesia 覆盖侠 v1.88.6**：自定义字体文件、在线字体、原生字体比例、排版、留白居中、滚动条和头像定位、双态实时预览与使用及主题 CSS 写入。**入口：底栏扩展菜单（魔法棒）**。
- **主题绑定壁纸 v4.1**：每个 UI 主题绑定原生背景图库壁纸，支持多图随机、跨文件夹选图，能与配套侠联动。**入口：原生背景面板顶部工具栏**。
- 两个脚本均独立安装和运行；TLE 根据 UUID 检测已安装脚本，不覆盖用户已安装的同 UUID 脚本。
- 下载从 GitHub Raw、jsDelivr、Fastly、TestingCF 多线路回退。验证固定仓库路径、Commit、UTF-8 字节数、SHA-256、完整 JSON、脚本 ID 和名称后才导入酒馆助手全局脚本列表。

## 保留原功能
- Bootstrap 1.0.6、Loader Runtime 0.3.6、校验与回滚机制均不改动。
- 渐隐侠、楼层侠、会话侠、诊断、TT ChatSurface 等现有功能不变。
- 覆盖侠 v1.88.6 在 iPhone TT 的字体比例调整已有用户实测成功反馈；本次新版 Core 自动更新链及功能包安装流程仍需要发布后在各设备进一步验收。
