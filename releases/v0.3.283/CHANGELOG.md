## 2026-11-27 · Core v0.3.283 · 记录预览头像样式独立化（测试分支）

- 记录预览不再克隆酒馆主题的整个 `.avatar` 容器，改为独立的 TLE 头像框；只复制原头像图片节点，保留 `src` / `srcset`，剥离主题 class、inline style、ID 和固有宽高属性。
- 固定头像卡片 2:3 比例、12px 圆角、`object-fit: cover`；头像框与图片统一无边框、无 border-image、无阴影、无滤镜和无伪元素装饰。
- 渐变遮罩直接贴合 TLE 头像卡片，不再依赖主题头像的实时尺寸、圆角或运行时几何测量，减少布局读取。
- 移除旧的「记录预览头像兼容」可选开关；升级时自动清理已存在面板中的旧选项。
- 所有样式严格限定在 TLE 首页记录预览，不改动酒馆原生最近聊天、角色列表、聊天头像或角色管理预览。

仅更新测试分支；正式 Core、Stable Loader 与 Bootstrap 不变。
