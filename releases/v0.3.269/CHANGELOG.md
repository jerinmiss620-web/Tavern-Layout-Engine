# Core v0.3.269 TEST · 记录预览渐变过渡优化

## 本次修正

根据 v0.3.268 实机截图，底部信息区的渐变虽然已经放在正确位置，但渐变区域过短，透明到深色的变化集中在很小的范围内，形成明显的横向色带。

- **扩大渐变区域：** 信息区 `min-height: 48%`、`max-height: 60%`，为透明到深色的过渡留出更长距离。
- **平滑过渡：** 将原先三个停靠点扩展为七个停靠点，透明度从 0 逐步经过 0.035、0.12、0.32、0.56、0.78 到 0.92。
- **内容保持底对齐：** 信息区增加 `justify-content: flex-end`，角色名、日期、概要和统计信息仍贴近卡片底部，不会因为渐变区域变高而上移。
- **保留原结构：** 2:3 头像、底部锚点、最多两行概要、三个原生操作按钮及其行为均不变。
- **代码：** 直接替换原有信息区 CSS 规则，并更新回归断言；不叠加补丁。

## 验收清单

1. 渐变从头像下方更高的位置开始，顶部保持近乎透明。
2. 透明到深色之间有连续、柔和的中间层次，不出现突兀的横向色带。
3. 角色名、日期、操作按钮、两行概要和统计信息仍贴近卡片底部。
4. 两行概要限制、头像比例、操作按钮行为不回归。
5. 在 ST / TT PC 与移动端、不同主题和明暗头像下检查视觉效果。

**状态说明：** 自动化断言覆盖渐变区域高度、底部对齐和渐变停靠点；最终视觉效果仍需实机截图验收。
