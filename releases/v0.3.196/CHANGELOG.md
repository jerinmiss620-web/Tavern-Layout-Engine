# TLE v0.3.196 — Chat Tools UX and Navigation Compatibility

## 楼层侠：双输入框与清除操作

- 将原有「楼层跳转 / 隐藏楼层 / 恢复楼层」三个输入行收敛为两个输入行。
- 第一行仅用于楼层跳转，继续使用 `/chat-jump mesid`，不要求输入范围连接符。
- 第二行共用一个楼层范围输入框，分别提供「隐藏」和「恢复」按钮；执行命令时始终规范化为 `x-y`，单层操作也必须写成 `90-90`。
- 两个输入框均在有内容时显示右侧清除按钮，可清空后立即重新输入。
- 保留当前聊天识别、楼层上下界校验、斜杠命令执行结果检查、防重复提交和隐藏范围统计。
- 跳转输入支持 Enter 提交；范围输入需要明确点击「隐藏」或「恢复」，避免 Enter 时无法判断用户意图。

## 兼容性修复：侧边导航按钮

- 在现有「兼容性修复」区域增加独立的「修复侧边导航按钮宽度与图标可见性」选项，默认关闭。
- 仅作用于 TLE 接管导航时的 `#top-settings-holder` 原生抽屉按钮。
- 将按钮宽度恢复为自适应内容宽度，避免第三方主题的 `width: 100% !important` 将图标按钮拉伸并挤压标签布局。
- 恢复 `.drawer-toggle`、其伪元素、`.drawer-icon` 及其伪元素的 `opacity` / `visibility`。
- 不替换、不重绘、不指定主题图标贴图；保留原主题图标载体与视觉素材。
- 新开关写入本地设置，并纳入诊断报告；卸载 TLE 时清理对应 body 标记。

## 会话侠：可选聊天快捷操作

- 在「聊天界面功能」设置中增加独立开关，默认关闭。
- 开启后在会话侠标题栏显示「新建」「关闭」「文件」三个快捷入口。
- 分别调用 SillyTavern 原生的 `option_start_new_chat`、`option_close_chat`、`option_select_chat`，继续使用酒馆原有确认、历史聊天管理和关闭流程。
- 仅从原生 `#options` 菜单中查找操作入口；对重复的 `option_close_chat` ID 做显式选择，避开带 `displayNone` 的隐藏副本，避免误触其他扩展的同名元素。
- 快捷操作只存在于会话侠弹窗内；没有新增常驻悬浮按钮，不改变欢迎界面和底栏原生菜单。

## 诊断与维护

- 诊断报告新增导航兼容修复开关状态、会话快捷操作开关状态。
- 新增的导航兼容 body 标记纳入初始化清理与 destroy 清理。
- 继续沿用现有样式区与事件委托结构，不追加零散 CSS 覆盖规则。

## 导航间距与 JS 点击诊断

- 在兼容性修复开启时，仅对「图标 + 文字」（`labels`）和「图标 + 文字 + 信息站」（`info`）两种导航模式，将原生 `.drawer-toggle` 的 `margin-inline` 设置为 `15px !important`。
- 极简纯图标模式不增加该间距；关闭兼容性修复时不生效；普通导航规则不变。
- Host Diagnostics 新增原生导航按钮的计算样式、`::before / ::after` 伪元素、祖先 `pointer-events`、可见性、几何位置及 `elementsFromPoint()` 命中栈。
- 新增被动点击追踪：记录按钮区域的 pointerdown / click 实际命中目标、事件是否到达 document/window 冒泡阶段、`defaultPrevented` 状态，以及点击前后抽屉是否真正切换。
- 诊断只观察，不阻止事件、不模拟点击、不重写第三方 CSS；可据此区分遮挡、`pointer-events` 拦截、事件传播中断和点击处理未生效。
