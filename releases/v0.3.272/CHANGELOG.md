# Core v0.3.272 TEST · 记录预览操作栏紧凑布局

## 本次修正

记录预览卡片底部的置顶、重命名、删除按钮此前沿用酒馆原生 `.menu_button` 的默认尺寸和内边距，按钮组占用空间过大，导致日期只能被压缩省略。

- **操作按钮：** 保留原生按钮节点、图标和点击行为，将三个图标按钮统一压缩为 24 × 24px，图标居中，清除多余内边距和外边距。
- **按钮间距：** 继续使用 2px 间距，不再让每个按钮保留原生的大块空白。
- **日期：** 改为弹性填充剩余空间；只有在实际空间不足时才省略。
- **行布局：** 日期与按钮组之间固定留出 6px；按钮组不再使用自动外边距抢占空间。
- **颜色：** 继承 v0.3.271 的统一白色配色，日期、置顶/编辑/删除图标及统计颜色不回退。
- **保持不变：** 头像比例、卡片圆角、渐变、文字预览、按钮功能及数据处理逻辑。
- **性能：** 仅修改已有 CSS 规则，不增加脚本逻辑、监听器、轮询或额外渲染。

## 验收清单

1. 日期应尽可能完整显示，不再无故缩成 `202...`。
2. 三个操作按钮紧凑排列，图标居中，不再各自占据过大的宽度。
3. 置顶、重命名、删除均可正常点击。
4. 日期与按钮在不同卡片宽度下不重叠。
5. v0.3.271 的统一白色配色继续生效。

**状态说明：** 本版本仅更新测试通道，待酒馆环境实机验收后再决定是否发布正式版。
