# Core v0.3.288 · 角色记录、首页画廊与正式版修复整合

## 本版更新

- 正式整合首页角色画廊与角色记录预览；保留酒馆原生角色头像预览区域，不另建一套角色管理系统。
- 角色记录详情提供角色资料、绑定世界书与聊天记录入口；减少重复操作按钮。
- 记录展示头像采用独立显示约束，统一比例、圆角与边框表现；不改写聊天消息头像和酒馆原生角色列表头像。
- 整合高清头像兼容与主题圆角适配，避免主题切换后记录预览头像出现窄图、比例偏差或渐变边缘错位。
- 整理侠保留资源分组、批量操作、世界书绑定核对及独立查找替换入口，继续继承酒馆原生控件样式。
- 完整保留正式版 v0.3.264 的配套方案紧凑预览（5px 0、无横向分割线）和原生更新按钮规则（仅 `menu_button`，不使用 `tle-update-pill` / `tle-update-check`）。
- 移动端记录详情在 820px 断点内，将 `--freesia-gallery-detail-main-gap` 设为 `5px`；头像列宽 104px、列间距 8px 保持不变。
- 所有样式修改合并在原有规则中，不新增后置覆盖补丁。

## 发布边界

- Core：v0.3.288。
- Loader Runtime：继续使用 v0.3.6，不变。
- Permanent Bootstrap：继续使用 v1.0.6，不变。
- 原正式版 v0.3.264 的不可变源码与历史 Commit 保留，不覆盖、不重写。
