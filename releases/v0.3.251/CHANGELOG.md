# TLE v0.3.251 — Test

## 整理侠：分组管理重新设计

- 移除原来的「管理分组 / 收起管理」展开表单，不再依赖先打开管理区、再点选目标、再操作按钮的多层状态。
- 分组目录改为直接可点击的原生 `.menu_button` 列表；选中项有明确状态，目录行本身负责切换当前查看分组。
- 「新建分组」改为独立入口，按需展开名称输入；创建后自动选中刚创建的分组。
- 重命名和删除直接绑定左侧当前选中的分组，不再借用右侧批量归组目标；重命名采用内联编辑，删除增加二次确认。
- 右侧「选择目标分组」只负责批量归组，不再意外改变左侧当前查看/管理的分组。
- 删除分组只移除分组关系，不删除资源；组内项目会移回「未分组」。若删除的分组正是批量归组目标，才清空该目标；其他目标保持不变。
- 修复内容操作重复获取锁时覆盖原始 disabled 状态的问题，确保操作结束后分组目录和管理按钮恢复可用。
