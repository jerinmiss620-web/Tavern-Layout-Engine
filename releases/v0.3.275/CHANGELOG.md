- **背景优先级：** 主题直接设置 body/html 的 CSS 渐变图像时使用原生背景；#bg1 有真实壁纸图片时保留镜像路径；无壁纸图片、仅有色层时优先选择主题原生纯色背景。

- **状态清理：** 复用清理函数，切换背景模式时清掉旧壁纸伪元素、CSS 变量和渲染状态。
- **性能：** 按需 MutationObserver / ResizeObserver + requestAnimationFrame；不使用轮询或在 #chat 内插入新节点。
- **兼容：** 不修改渐隐遮罩、70px 底部留白、毛玻璃和其他 TLE 功能。
