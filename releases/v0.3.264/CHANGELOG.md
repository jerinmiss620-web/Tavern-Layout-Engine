# Core v0.3.264 · 配套侠修复与紧凑预览、更新按钮原生化（正式版）

- **全局世界书纳入配套方案：** 保存当前配置时记录所有已启用的全局世界书；编辑器支持多选并保留无法读取的旧条目标记；应用时按保存的完整清单同步可用书目，缺失或不可修改的条目逐项提示，其余项目继续应用。
- **默认方案恢复：** 区分完整宿主页面启动与同页面 Core 更新/重新启用。TT/ST 启动恢复上次聊天后，即使角色上下文早于 TLE 事件监听器加载，也能恢复当前角色默认方案；同页面热更新不重复覆盖手动配置。上下文延迟时有限重试。
- **默认方案入口：** 方案列表与方案管理页均提供「设为默认 / 取消默认」，切换默认时自动替换上一方案。
- **方案预览：** 方案列表和管理页共用字段化双列预览。删除字段横向分割线及方案卡片底部分割线；保留默认方案的竖向状态标记；压缩字段内边距、列间距、行间距与标题区留白，长文本仍自动换行，全局世界书继续占整行。
- **更新按钮：** 五个 Core/Loader 更新、检查与接管按钮只保留酒馆原生 `menu_button` 类；移除自定义更新按钮标记类及视觉覆盖，不改点击、隐藏、禁用和安装逻辑。
- **整理侠：** 保留移动端标题顺序、查找替换操作区紧凑布局与结果列表独立滚动等 v0.3.262 修复。
- Loader Runtime v0.3.6 与固定 Bootstrap v1.0.6 不变；本次只发布 Core。

## 自动化与实机验收范围

- Node 24 全量回归、配套侠初始化/世界书/预览布局断言、发布清单与不可变源码核验，以及合并后的远端更新链重放均纳入发布门禁。
- 自动化通过不等于所有 ST/TT、主题与移动端组合均已实机验证；具体范围记录在仓库 `VALIDATION.md`。
