# v0.3.298 · 打码侠统一作用范围与名称替换修复

基于测试 Core v0.3.297 继续开发；仅更新独立 Mask Hero Test 通道，不修改正式版 v0.3.294。

## 本轮修复与调整

- 修正名称替换选择器为 `.mes_block > .ch_name .name_text`，兼容 `.ch_name` 内部存在多层 `.flex-container` 的实际 DOM。
- 将「统一作用范围」提升为打码侠全局规则，放在配置顶部，默认「全部楼层」。
- 支持「全部楼层」「最新 N 层」「指定楼层范围」；最新 N 层动态按当前聊天中的 User / Char 消息数量计算，系统消息不计入。
- 统一范围控制 User / Char 名称替换、头像覆盖、正文整体替换、正文局部替换，以及单独楼层替换。
- 为正文整体替换增加独立启用开关；选择作用范围不会自动开启任何打码功能。
- 单独楼层替换不得越过全局范围；范围外的名称、头像和正文局部 / 整体替换会恢复原始显示。
- 新消息进入最新 N 层窗口时自动应用；被挤出窗口的旧消息自动恢复。
- 旧方案自动迁移：保留原正文整体替换开关与旧的范围设置；原来未启用整体替换的方案仍保持关闭，默认全局范围回退为全部楼层。

## 自动化验证

- 新增实际嵌套 DOM 结构的名称选择器回归检查。
- 新增全局范围、最新 N 层动态恢复、头像恢复、正文局部替换、单独楼层越界拦截及旧方案迁移测试。
- 自动化测试通过不等同于 ST / TT 实机验收；仍需检查主题 DOM、移动端布局和新消息动态恢复。
