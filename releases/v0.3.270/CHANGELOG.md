# Core v0.3.270 TEST · 记录预览头像圆角同步

## 本次修正

记录预览的头像图片会按酒馆用户设置呈现圆形、方形或圆角；底部渐变由独立覆盖层绘制，之前没有跟随头像的圆角，导致卡片底部出现直角渐变。

- **普通头像：** 记录预览卡片读取与原生 `.avatar img` 相同的 `--avatar-base-border-radius-round` 变量。
- **big-avatars：** 当 `body.big-avatars` 生效时，改用与原生大头像相同的 `calc(var(--avatar-base-border-radius) * var(--big-avatar-border-factor))` 计算。
- **统一裁切：** 圆角设置应用在最外层 `.freesia-gallery-card`，由其现有 `overflow: hidden` 同时裁切头像与底部渐变；渐变本身不另设固定圆角。
- **动态适配：** 直接使用酒馆现有 CSS 变量和 body 状态类，不缓存圆角数值、不增加 JS 监听或轮询；用户调整头像形状时由 CSS 重新计算。
- **保持不变：** 2:3 头像比例、渐变曲线和高度、底部信息排列、两行概要上限、三个原生操作按钮及其行为。
- **代码：** 在原卡片规则中整合圆角控制，新增 big-avatars 专用覆盖规则；Core 与独立画廊源码保持逐字一致，不追加补丁。

## 验收清单

1. 普通头像圆形设置下，渐变底部与头像圆角一致。
2. 普通头像方形设置下，渐变底部随之变为直角。
3. 普通头像圆角矩形设置下，渐变底部使用相同圆角。
4. 开启 big-avatars 后，渐变使用大头像自己的圆角计算。
5. 修改头像形状设置后，无需刷新脚本即可由 CSS 变量重新计算。
6. 头像比例、渐变、文字位置、两行概要和操作按钮不回归。

**状态说明：** 自动化测试覆盖普通头像与 big-avatars 两套圆角规则；最终形状仍需在酒馆用户设置中切换验证。
