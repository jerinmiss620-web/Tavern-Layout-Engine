# TLE v0.3.253 — Test

## 整理侠：分组管理交互重做

- 移除常驻的「分组操作：重命名 / 删除分组」操作栏；普通模式不再显示分组管理面板。
- 将「管理分组」图标按钮放到「新建分组」旁边；「新建分组」「管理分组」「自动分组」统一使用酒馆原生 menu_button 图标按钮，名称通过悬停提示和 aria-label 提供。
- 点击「管理分组」后才显示管理面板：提示系统目录不可操作，提供重命名当前自定义分组和批量删除已勾选自定义分组的图标按钮。
- 管理模式下，仅自定义分组出现复选框；「全部项目」「未分组」没有复选框，不能重命名或删除。
- 批量删除先列出分组名称与受影响资源数量，再二次确认；只删除分组定义及其归属映射，不删除资源，被移除分组中的资源回到「未分组」。
- 切换分类或退出管理模式会清空临时勾选；切换当前查看分组不会混淆批量操作目标。
