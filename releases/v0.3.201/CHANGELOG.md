# TLE v0.3.201 TEST — 楼层输入提示与导航图标透明度滑块

> 仅测试分支；正式版与稳定版清单保持不变。

## 楼层侠输入提示
- 跳转占位符明确为“输入楼层数字（mesid）”。
- 范围两个独立输入框占位符分别为“起点数字”“终点数字”。
- 在范围行下方显示简短说明：“两框均输入数字；只隐藏或恢复 1 层时，两框填同一个数字（例如 90 - 90）。”
- 为范围两个输入框追加 `aria-describedby`，屏幕阅读器也可读取说明。
- 已有 `/hide x-y`、`/unhide x-y` 自动拼接及验证行为保留。

## 导航图标透明度
- “导航栏样式”增加实时滑块，默认 **70%**，范围 **40%–100%**，步进 5%。
- 图标 `.drawer-icon` 原先的 `opacity:1!important` 改为 `opacity:var(--tle-nav-icon-opacity,0.7)!important`，不另加相互竞争的补丁。
- 覆盖主题强制的 `opacity:0!important`，保留 `::before` 自定义图案；点击、对齐用的 44px 槽位不变。
- 输入时即时生效，change 时保存 `tle.navigation.iconOpacity`；下次打开恢复用户设置，卸载时清除 body 上的临时变量。
- 诊断报告增加 `navIconOpacity`。

## 保留功能
- 继承 v0.3.200 TEST 的双范围输入、三个会话侠原生快捷操作、渐隐侠、TT ChatSurface、按钮命中修复。
- 仅通过静态语法及结构检查，仍需 ST / TT 真机界面验证。
