## 2026-11-27 · Core v0.3.279 · 记录预览独立圆角与显示范围（测试分支）

- 记录预览卡片使用独立 16px 圆角；卡片、身份层、头像容器与图片统一继承卡片裁切，不再受主题圆形头像规则或 `body.big-avatars` 影响。
- 首页原生最近聊天设置弹窗新增「显示范围」：默认只显示有聊天记录的角色，按最近聊天时间排序；也可显示全部角色，有聊天记录者优先，未聊过的角色排在后面。
- 每页显示数量继续由网格列数 × 行数决定，保留分页；切换显示范围时重新读取数据。
- 为准确识别不同角色的最近聊天记录，画廊请求最多读取最近 1000 个聊天文件；不增加逐角色请求或轮询。

仅更新测试分支；正式 Core、Stable Loader 与 Bootstrap 不变。
