# TLE Core v0.3.214 — 导航手势与兼容性优化

## 侧边栏文字颜色兼容
- 「兼容性」新增可选的侧边栏文字颜色自定义：提供拾色器和 HEX 输入，供日间主题与深色侧栏文字对比不足时使用。
- 只针对 TLE 左侧栏问候语、导航文字、信息站文本与栏内文字控件，不干预酒馆原生图标、正文和其他面板；默认关闭，关闭即移除颜色覆盖。

## 可选滑屏导航与原生手势联动
- 「导航交互」新增「滑动开关侧栏（自动关闭原生翻页）」开关，默认关闭；从屏幕左侧窄边缘右滑展开，在已打开的侧栏内左滑关闭。原汉堡按钮继续可用。
- 启用时调用 SillyTavern 自身的 `#gestures-checkbox` 的 `change` 事件，取消原生「左右翻页手势」并沿用原生设置保存；关闭时仅恢复 TLE 曾主动关闭的原设置，原本已经关闭的选项不被擅自打开。回复切换箭头不受影响。
- PC 浏览器可通过移动设备触摸模拟测试，不以操作系统 UA 限制触摸监听；普通鼠标拖动不作为触屏手势。
- 手势监听为被动触摸事件，不调用 `preventDefault()` 抢占系统返回。安卓默认不启用，使用者可主动测试；与系统返回／侧滑导航冲突时应关闭选项。

## 验证范围和兼容提示
- 用户确认 PC 触摸模拟和 iPhone 上滑动导航可用；安卓设备尚未验证普遍兼容性，实际可能调出系统导航或退出应用，故不宣称安卓可用。
- 保留隐藏原生抽屉的状态检查与输入框焦点兼容，避免滑屏只在首次展开后有效。
- 本版本只更新 Core；Bootstrap v1.0.6、Loader Runtime v0.3.6、内置配套侠与可选功能包本体均不更改。旧版正式产物不可变。
