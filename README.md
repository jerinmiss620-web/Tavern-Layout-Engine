
# Tavern Layout Engine (TLE)

A modular layout and interface enhancement engine for SillyTavern and TauriTavern.

酒馆布局引擎 · 由小松鼠 & ChatGPT（小松7）共同开发。

## Project

TLE enhances the Tavern interface with customizable navigation, workspace layouts, chat utilities, diagnostics and optional visual modules.

## Supported Hosts

- SillyTavern (ST)
- TauriTavern (TT)

## Distribution

The project is preparing a versioned remote-update system based on Tavern Helper scripts.

Users will eventually be able to install the loader once and receive future updates without repeatedly importing script JSON files.

Remote update infrastructure is under development.
