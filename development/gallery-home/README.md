# Freesia Gallery · 首页角色画廊 v0.2.13 TEST

独立测试模块。当前只改造 SillyTavern 欢迎首页，不接入 TLE Core，不修改 Bootstrap、导航栏、整理侠、信息站或正式频道。

## 产品结构

### 1. 首页角色画廊

- 以酒馆完整角色列表为数据源；即使角色没有最近聊天，也保留角色卡。
- 网格列数可选 2、3、4 列，任何屏幕宽度都不会自动增加到 4 列以上；当前列数由独立设置控制。视口宽度不超过 480px 时自动限制为最多 3 列，并临时禁用 4 列选项；回到更宽屏幕后恢复桌面设置。
- 每页行数可选 1～15 行，默认 3 行；每页最多创建 60 张角色卡（4 列 × 15 行），通过分页浏览完整角色库，避免一次性创建全部卡片 DOM。
- 每页设置保存在独立的账号存储键 `freesiaGallerySettings`，不覆盖酒馆原生 Recent Chats Settings；设置控件追加在原生齿轮打开的 Recent Chats Settings 弹窗中，复用原生保存/取消入口，不在首页额外占位。
- 画廊卡片和角色详情头像统一使用 3:4 竖版比例。详情页采用左右双列；桌面端资料区与头像等高，移动端资料区按内容自然收缩，描述框保留约三行高度，不强行撑满头像高度。图片使用 `object-fit: cover`。
- 网格间距统一为 `clamp(5px, 0.7vw, 8px)`；2/3/4 列均通过 `minmax(0, 1fr)` 均分剩余宽度，不固定卡片宽度。
- 每行等高，卡片使用统一的内部结构：头像、单行角色名称、最近聊天信息。聊天数量覆盖在头像左下角，不增加背景遮罩；文字使用 12～14px 自适应字号、常规字重和轻量 drop-shadow，并允许指针操作与文本选择；角色置顶按钮位于角色名称下方的独立操作栏，不覆盖头像。
- 最近聊天信息区固定为日期、两行预览、底部统计三个独立区域；日期与预览强制左对齐，统计区强制右对齐，避免继承主题中的居中排版。
- 角色名称居中显示；聊天数量完整保留，重命名/删除按钮与独立的角色置顶按钮分行展示，避免三列窄卡片中数量和操作按钮互相挤压；日期独占一行且左对齐，聊天预览固定预留两行高度，消息统计行保留完整行高。
- 消息数与文件大小放在预览下方的独立统计行，不再与聊天概要并排挤占预览宽度。
- 没有最近聊天的角色仍保留日期占位、两行预览区域、统计区域与工具栏占位，避免卡片高度缩短。
- 卡片上半区（头像、角色名、聊天数量）点击进入我们自己的角色详情页。
- 卡片下半区（最近聊天日期、聊天预览）点击直达该角色最近一次聊天。
- 最近聊天预览最多两行；显示日期、消息数、文件大小。
- 画廊首页卡片提供独立的「置顶角色」按钮，以及转发给酒馆原生最近聊天 DOM 的重命名、删除按钮。角色置顶按钮位于头像右上角；重命名、删除按钮与最近聊天日期处于同一行，明确表示它们操作的是该角色的最近聊天，而不是角色本身。没有最近聊天的角色不显示聊天级操作按钮。角色置顶保存在独立账号存储键 `freesiaGalleryPinnedCharacters`，只改变画廊角色卡排序，不改写酒馆原生 `pinnedChats`；切换回原生最近聊天模式时，酒馆原生界面保持不变。
- 聊天数量通过 `POST /api/characters/chats` 的 `simple: true` 延迟读取；只为当前可见卡片读取，避免首页一次性请求所有角色。
- 没有最近聊天的角色仍显示卡片，日期显示占位符、预览显示“暂无最近聊天记录”，不会伪造最近聊天入口。

### 2. 角色详情页

点击角色卡上半区进入独立详情页：

- 左侧显示 3:4 角色头像；右侧名称、描述标题和描述框与头像组成等高的资料区域。移动端仍保持左右两列，不把描述框拆到头像下方；描述框自动填满右侧剩余高度，不得高于头像。
- 右侧显示角色名称、角色主世界书绑定名称（未绑定时不显示）。
- 角色描述以只读 textarea 展示，沿用酒馆 `#description_textarea` 的原生类名以继承 `.text_pole` 与当前主题；不复制原生文本框的固定高度或内联尺寸。桌面端由右侧弹性布局填充，移动端固定为约三行高度。
- 标题区只显示角色名称与实际绑定的主世界书名称，不添加 `Char's lorebook` 等示例性英文前缀。移动端「详情/管理」按钮缩小为紧凑高度，避免标题行被按钮撑高。
- 「详情/管理」按钮放在「角色描述」标题行最右侧，不与页面标题或角色名称挤在一起。按钮不带 `>` 箭头。
- “详情/管理”按钮只负责跳转到酒馆原生角色编辑界面：调用原生 `selectCharacterById(index, { switchMenu: true })`。角色编辑、世界书绑定管理等全部归酒馆原生界面负责，本项目不重造管理功能。
- 下方显示该角色的聊天文件总数、最新聊天及其他聊天记录。每条聊天记录提供置顶、重命名、删除三个操作；置顶仅作用于当前角色详情页的聊天列表，使用独立账号存储，不改变酒馆首页全局最近聊天置顶状态。聊天名称居中显示。
- 最新聊天和会话条目点击后打开对应聊天。

### 3. 聊天文件页

- 从详情页的“聊天文件”进入；按钮不带 `>` 箭头。
- 使用酒馆原生 `POST /api/chats/search` 读取该角色全部聊天文件的名称、时间、预览、消息数和文件大小。
- 提供文件名与预览内容搜索。
- 点击任意聊天文件打开对应聊天；若聊天不在首页最近聊天范围内，则使用酒馆上下文的 `selectCharacterById` 和 `openCharacterChat` 打开。

## 原生设置和原生能力

- 欢迎首页顶部隐藏大蜘蛛 Logo，但保留 SillyTavern 完整版本文字；画廊标题与版本文字占据左侧可伸缩空间，齿轮、关闭、画廊/原生切换按钮靠右排列。
- 原生显示/隐藏最近聊天、Recent Chats Settings 齿轮与画廊/原生视图切换仍保留；切回原生最近聊天时恢复酒馆原有 Logo 与版本显示。
- 返回按钮与角色数量摘要留在次级标题行左侧；文档、GitHub、Discord、临时聊天等原生快捷入口整体靠右。
- 列数与每页行数设置统一通过原生最近聊天设置齿轮打开，不在首页次级标题行额外占位。
- 进入角色详情或聊天文件页时，分页和角色数量摘要隐藏；只有返回画廊后才恢复。布局设置统一通过原生最近聊天设置齿轮打开。
- 返回按钮放在次级标题行，避免与页面标题挤在一起；原生快捷入口保留。
- 顶部摘要只显示角色总数与分页位置；列数和行数只由下方设置控件表达，不重复显示。
- 直接读取账号存储 `recentChatsSettings`：
  - `maxDisplayed`：传给 `POST /api/chats/recent` 的 `max`，决定用于最近聊天预览与排序的聊天文件数量。
  - `collapsedDisplayed`：仅由酒馆原生最近聊天列表使用，不再控制画廊显示数量。
- 酒馆原生 `pinnedChats` 仍用于识别原生置顶聊天；画廊另有独立的角色置顶状态，两套置顶互不覆盖。
- 顶栏增加画廊/原生最近聊天切换入口。原生模式下原始最近聊天列表和群聊仍可访问。
- 详情页会话列表与聊天文件列表使用酒馆原生 `.recentChat` / `.recentChatList` 结构及其子类（`.recentChatInfo`、`.chatNameContainer`、`.chatMessageContainer`、`.chatStats`），不另造卡片底色、边框或圆角。
- 停用脚本会移除新增 DOM、CSS、事件监听，并恢复原生首页；不会改写酒馆角色数据或聊天文件。

## 独立加载测试

v0.2.13 调整头像左下角聊天数量的可读性：字号改为 12～14px 自适应，字重由 600 降至 500，drop-shadow 收紧为 1px 模糊，并恢复指针响应与文本选择；不添加渐变背景，不使用 text-shadow。角色置顶按钮仍位于角色名称下方的独立操作栏。

在酒馆首页 Console 执行：

    const s = document.createElement('script');
    s.src = 'https://cdn.jsdelivr.net/gh/jerinmiss620-web/Tavern-Layout-Engine@a0c5ec4e6e60cb910b6940361117a9dce237bb4a/development/gallery-home/Freesia-Gallery-Home-0.2.13.js';
    s.onload = () => console.log('Freesia Gallery loaded', window.FreesiaGalleryHome?.version);
    s.onerror = error => console.error('Freesia Gallery failed to load', error);
    document.head.appendChild(s);

控制台接口：

- `window.FreesiaGalleryHome.refresh()`：重新读取首页最近聊天与角色卡。
- `window.FreesiaGalleryHome.toggleView()`：画廊/原生最近聊天切换。
- `window.FreesiaGalleryHome.openDetail('角色头像文件名.png')`：打开指定角色详情。
- `window.FreesiaGalleryHome.openFiles()`：打开当前角色聊天文件页。
- `window.FreesiaGalleryHome.getSettings()`：查看当前读取的原生最近聊天设置。
- `window.FreesiaGalleryHome.getPage()`：查看当前页面。
- `window.FreesiaGalleryHome.stop()`：停用并恢复原生首页。
- `window.FreesiaGalleryHome.start()`：重新启用。

## 当前边界

- 本版只处理首页画廊、角色详情和聊天文件浏览。
- 画廊每页最多 15 行；更大的角色库通过分页访问，不会一次性把全部角色卡放进 DOM。
- 角色管理、角色资料编辑、世界书绑定编辑均跳转酒馆原生界面，不在本项目内实现。
- 群聊仍保留在原生最近聊天模式中；本版画廊主体展示单角色卡。
- 暂不与 TLE 整合，先独立完成视觉与交互验收。
